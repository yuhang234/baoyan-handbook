# 论文写作与修改笔记

这篇不是写作教程，是我写论文时真正用过的几套方法笔记：怎么把 AHP 建模写成方法章节，怎么设计教学效果评估，以及逐版修改时我在改什么。

## 方法章节不是先写的，是先做的

我吃过「边写边想方法」的亏。后来改成先写方法笔记再写论文：把建模动机、层级结构、每一步计算都先用中文写给自己看，逻辑通了再翻译成论文语言。我的方法笔记里有一节叫「建模动机与方法定位」，写的是 AHP 在论文里到底扮演什么角色——这个问题的答案后来直接成了论文里的段落。

## AHP 建模：把定性判断变成可辩护的数字

论文里六类课堂行为要变成认知参与度权重，我用的 AHP，整个过程可以拆成四步，每一步都要在论文里交代清楚：

1. **理论定位**。先说明 AHP 不是用来「发现」行为重要性规律的，而是把教育学理论里的定性判断转化为可计算权重的形式化工具。这句话决定了整节的合法性——审稿人会追问你的权重凭什么，答案必须是「来自理论的约束」，不是「我拍的」。
2. **判断矩阵**。两两比较六类行为，比如站立对抬头是 3（更重要 3 倍），站立对趴桌是 1（同等重要）。矩阵里每个数都能追溯到一句教育学理由。
3. **一致性检验**。算最大特征值、CI、CR，CR 小于 0.1 才算通过。我们的矩阵一次没过——站立和趴桌的相对关系不对称——修了对称性才过。
4. **双算法对照**。算术平均法和特征向量法各算一遍，两套权重（站立 0.298、趴桌 0.279、玩手机 0.183、抬头 0.122、低头 0.071、回头 0.047）几乎一致，互为稳健性证据。

这套写法的关键是：**每个数字都有出处，每个选择都有对照。**

## 评估设计：别让统计毁掉一个好研究

验证系统对教学有没有用，我采用单组前后测设计：同一批学生，系统引入前后的成绩对比。写这一节时固定动作是：变量定义（自变量、因变量、控制变量各是什么）、数据预处理（样本筛选、缺失值剔除、异常值检查）、统计流程（先用 Shapiro–Wilk 检验正态性，正态就用配对 t 检验，非正态用 Wilcoxon 符号秩检验，显著水平 0.05），最后补 Cohen's d 报效应量——显著性只说明「有差异」，效应量才说明「差异有多大」。

## 逐版修改时我在改什么

我的论文有多个版本的草稿，回头看每一版的差异其实很规律：

- **第一版**的问题是把「我们做了什么」当成了论证。修改时把每一段都改写成「领域缺什么—我们做了什么—证据是什么」。
- **中英双稿并行**是我踩过最大也最有价值的坑。中译英不是翻译，是重写：中文习惯的排比和铺陈在英文论文里全是冗余，英文一句只说一件事。
- **参考文献跟着论证走**。每个关键论断后面挂引文，引不出来的论断要么补文献，要么删掉。这个规则让「我认为」三个字从正文里基本消失了。

## 最有效的一次「修改」

回头看，让论文真正变清楚的修改几乎都不是我一个人闷头想出来的，而是审稿人和技术检查的问题逼出来的。被拒之后改投那阵子，逐点回复逼我把每个决定写成一句清楚的话；摘要按新期刊的口味重写后发给合作者，他的回信让我立刻看出哪里跑偏。

所以我对写作的建议只有一条：**尽早把稿子交给会回你的人。** 写作的一半工作不是写，是收集反馈。
