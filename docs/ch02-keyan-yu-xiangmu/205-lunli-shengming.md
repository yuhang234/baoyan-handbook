# 涉及人的研究：伦理与知情同意

只要你的研究拍到了人，伦理就是绕不过去的一关。我用课堂视频做的两项研究都踩过这条线上的坑，这篇把要准备的东西一次性讲清。

## 为什么课堂录像是个敏感活

课堂行为识别研究要录真实课堂，画面里是几十个可以被人认出来的学生。这带来三个伦理问题：采集是否知情、数据怎么存、发表时怎么用。国际期刊对此有硬性要求，技术检查一定会查。

## 知情同意：两句话都不能少

投稿时编辑要求我们补充确认，最后写进扉页的是两句话：

- 所有参与学生在数据采集前被告知研究目的与流程，并签署**参与知情同意**与**发表知情同意**的书面文件；
- 所有参与者均为 18 岁及以上的大学生，因此不涉及监护人同意。

第二句话容易被忽略——审稿人看到学生画面会本能地想「是不是未成年人」，你要主动把这个疑虑消掉。

采集现场的做法也要配套：录制前向所有同学说明摄像机用途和数据存储方式（仅用于研究分析，不泄露个人信息），采集过程不干扰正常教学。我们事后对比过，学生行为没有因为摄像机存在而明显变化，这既是数据质量保证，也是伦理上「无感观测」的底气。

## 伦理审批主体：没有校级伦理委员会怎么办

这是我最意外的一关。投稿时编辑要求附伦理审查机构名称，而**我们学校当时没有统一的校级伦理委员会**。我们的处理是如实说明：伦理审查与批准职责由相应的二级学院承担，审查主体写学院的正式名称，并写明批准的项目题目。

从技术检查通过的结果看，期刊要的不是「你必须有一个叫 IRB 的机构」，而是**有一个明确的、可追责的审查主体，并且你在稿子里写清楚**。含糊才是大忌。

## 数据与隐私的日常操作

除了声明，日常操作要和声明一致：

- 原始视频只存研究用途的存储位置，不外传、不做演示素材；
- 论文中的示例图选择远处或侧面的画面，能不出现正脸就不出现；
- 数据可用性声明里说明数据因含可识别画面不公开，但可以说明复现的代码和统计口径——我们改投时准备了复现仓库和补充材料，审稿人要核对的其实是这些。

## 时间上的建议

伦理材料要在**采集之前**准备好，而不是投稿前。采集前的知情同意书、事后补的审批文件，两者的效力完全不同；而且一旦开始采集再回头补同意，等于要重新采集一遍。我见过把这件事拖到最后的人，代价是整批数据作废。

涉及人的研究，伦理不是论文的附属品，它是研究资格本身。
