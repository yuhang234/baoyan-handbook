# 期刊选择与投稿入门

第一次投稿前，我被一堆名词糊过脸：SCI、SSCI、JCR、中科院分区、Q1、影响因子。这篇先把概念讲清，再讲我实际怎么选刊、怎么走流程。

## 先把名词捋顺

- **SCI / SSCI**：两大引文索引。SCI 偏自然科学，SSCI 偏社会科学。教育学、心理学、图书情报大多在 SSCI 里。
- **影响因子（IF）**：期刊前两年论文的平均被引次数，衡量热度，不衡量质量下限。
- **JCR 分区**：把同学科期刊按 IF 排序分成 Q1–Q4，Q1 是前 25%。
- **中科院分区**：国内常用，1–4 区，划分比 JCR 更收紧，1 区比例更小。同一本期刊 JCR Q1 但中科院 2 区很常见。

计算机要额外注意：CS 领域更看重 CCF 分级和顶会（CVPR、NeurIPS 这类），一本 IF 3–5 的期刊在 CS 里已经很好；而教育技术类 SSCI 里，Q1 期刊的 IF 可能还不如 CS 的水刊高——**跨区比较 IF 没有意义**。

## 选刊的三个实际标准

1. **范围匹配**。把候选刊最近两年的目录扫一遍，看有没有和你类似的问题、方法、场景。我改投时做的第一件事，就是发现新期刊最近收了好几篇「AI + 课堂分析」的论文，这比任何指标都说明范围合适。
2. **你引用的文献在哪发表的**。我的参考文献里有好几篇发在 Humanities and Social Sciences Communications，这本身就是这本刊适合我论文的证据。
3. **审稿周期和费用**。教育类 SSCI 普遍慢，一轮审稿几个月很正常；还要看清是否收版面费或开放获取费，别等录用才发现要一笔钱。

## 我自己的选刊路径

我的论文是计算机视觉加教育理论的交叉工作。第一轮投了一本教育技术领域 JCR Q1 的老牌 SSCI，被拒。复盘下来，主要问题是论文当时的理论包装不够，和那本刊的口味有偏差。

被拒之后我改投 Humanities and Social Sciences Communications（SSCI，JCR Q1），现在在稿。两轮下来我最直接的体会：**选刊不是选「最好的刊」，是选「最可能认真对待你这篇的刊」。** 排名靠前但范围偏一点点的刊，往往不如范围正中、排名稍后的刊走得远。

## 投稿流程长什么样

主流期刊都走线上投稿系统，大致流程：注册账号 → 填题目摘要关键词 → 上传正文、图、封面信（cover letter）、扉页（title page）→ 提交 → 编辑部技术检查 → 同行评审 → 决定（拒稿 / 修回 / 录用）。

两个新手容易忽略的点：

- **技术检查**是编辑部对格式、伦理声明、知情同意这些形式的审查，不过内容关。我的稿子在这里被提过两条意见，[审稿意见回复实战](204-response-shengao.md)里有完整经过。
- **投稿状态**会在线上系统里变化，从 With Editor 到 Under Review 再到各种中间态，状态几天不动很正常，不要反复催。

## 三个坑

- **只看 IF 选刊**。范围不匹配的刊，IF 再高也是白给一次拒稿。
- **一稿多投**。投稿时有原创声明，同时投多家属于学术不端，别碰。
- **把「在投」当成果说**。在投不算发表，简历上可以写状态，但面试要诚实说在哪个环节。
