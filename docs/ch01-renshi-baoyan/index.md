# 第一章 认识保研：流程、政策与信息搜集

保研不是一场考试，而是一条由资格、名额、截止日期组成的流水线。这一章把整条线摊开：先建立全景时间线，再逐条拆解硬性门槛和加分规则，最后教你管理报名信息和读懂政策文件。读完这一章，你应该能回答三个问题：我够不够格、接下来半年每个节点该做什么、去哪里核实规则。
