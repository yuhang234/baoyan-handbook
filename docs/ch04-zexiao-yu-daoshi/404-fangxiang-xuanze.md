# 研究方向怎么选

「你对什么方向感兴趣」是套磁和面试里必被问到的问题，而很多人的答案是一串热度词。热度词不是方向，面试官一追问就露馅。这篇讲方向选择的取舍逻辑：先定大前提，再定具体方向，最后讲怎么从导师主页判断真实方向。

## 先定大前提：读研为了什么

方向选择的第一变量不是兴趣，是读研目的：

- **就业向**：优先选工程量大、和产业接轨的方向，实验室放不放实习比论文产出更重要（判断方法见 406）。CV 后端、多模态应用、系统与基础软件都是就业面宽的选择。
- **读博/深造向**：优先选论文产出通道明确、导师学术资源强的方向，热度和产出效率要一起算。

这个前提定错了，后面全拧：想就业的人进了一个不放实习的强科研组，和想读博的人进了一个纯工程组，痛苦是等量的。

## 再定方向：三条判断依据

**一、看基本功，不看名词。** CV、多模态、具身智能这些标签下面，底层技能是相通的：检测、跟踪、时序建模、特征融合、大规模训练。我自己的路径是从课堂行为识别（YOLO 检测加多目标跟踪）延伸到多模态状态建模，再到面试前速成多模态融合的概念——新的只是名词组合，底座一直是那几样。选方向时问一句：这个方向的底座技能，和我已有的积累接得上吗？接得上，学习曲线就平；接不上，先掂量补课成本。

**二、看热度的另一面。** 大热方向意味着投稿人多、名额竞争激烈、算力门槛高。评估一个方向要看三样硬条件：数据好拿吗（有些方向的数据集就是垄断资源）、算力烧得起吗（课题组没卡你排队）、你毕业时的供需大概什么样。热度是别人的信号，供给才是你的现实。

**三、看交叉地带的机会。** 纯正赛道挤，交叉地带反而容易出活。我的论文把 CV 行为识别和教育学认知框架结合，投的是教育交叉方向的期刊——它不是 CS 顶会赛道，但「有领域问题 + 有方法支撑」的组合让整个故事好讲得多。计算机加医疗、加农业、加交通，逻辑都一样。

## 从主页判断老师的真实方向

选方向最终落到选导师，而**导师主页上的方向标签和真实方向可能相差很远**。我吃过这个功课的甜头，方法如下：

- 主页列「具身智能、大语言模型、AIGC」，点开论文列表一看，大部分成果在传感器融合和行为识别——那他的真实主线是「多源感知 + 智能评估」，大模型只是近两年的扩展。聊天时顺着他的老本行接话，比顺着标签接话稳妥得多。
- 看近三年论文的关键词分布，而不是主页 Research Interests 的措辞。主页是愿望，论文是账本。
- 拿不准就问在读学生一句话：「组里现在 X 方向是主线，还是刚起步？」这一句能省掉入组之后的巨大错配。

## 我的取舍记录

我是就业与深造兼顾的态度，方向上选了「视觉感知为底座、多模态为延伸」的组合：技能可迁移，就业有 CV 工程岗兜底，往上接具身智能和多模态大模型的叙事也顺。套磁时我不说自己「对具身智能感兴趣」，而是说「我的经历在行为识别和多模态状态建模，希望往具身智能的感知层方向衔接」——前一句是空话，后一句是有出处的判断。

## 判断清单

- [ ] 读研目的（就业/深造）先于方向；
- [ ] 目标方向的底座技能与自己的积累对得上；
- [ ] 数据、算力、供需三个硬条件都查过；
- [ ] 意向导师近三年论文的关键词分布摸过一遍；
- [ ] 能用一句话讲清「我的过去如何接到这个方向」，且这句话经得起追问。
