# 导师选择：方向、资源与匹配度

上一章讲了怎么收集评价，这篇讲拿到一堆评价之后怎么选。选导师最常见的错误是把「名气」当唯一变量，其次是把所有维度揉在一起凭感觉打分。我的做法是给维度排一个优先级，然后逐层过滤。

## 优先级：方向 > 匹配 > 资源 > 名气

**第一层：方向匹配。** 这是硬门槛，不满足直接出局。判断依据不是主页标签，是近三年论文的关键词分布（方法见 404）。方向不匹配的后果是三年都在做不想做的事，再好的组也待不下去。

**第二层：指导风格匹配。** 405 的四个维度里，「放养程度」和「指导频率」合起来就是你入组后的日常。选法只有一个原则：**你是需要外部反馈才能运转的人，就选指导密的组；你是自驱型、自己能给自己定计划的人，放养的组反而是自由。** 别高估自己——多数人低估了自己对反馈的依赖度。一个自查办法：回想你大学里效率最高的一段时间，靠的是自己的计划表，还是某门课的高频作业和deadline？答案基本就是你的真实类型。

**第三层：资源与毕业条件。** 算力、项目、经费决定你能做什么题；毕业要求决定你必须做什么题。两边都看：资源组里最好的题往往就在资源密集的方向上，而毕业要求决定了最低产出线——「发文硬性要求 + 自己不感兴趣的方向」是最危险的组合。

**第四层：名气与 title。** 大牛导师的背书在深造路径上有真实价值，但注意大组结构：大老板挂名、小导师日常带人的情况很常见。如果冲大牛，问清楚「新生日常由谁指导」——这个问题的答案才是你未来三年的真实体验。

## 大组与小组

- **大组**：方向多、资源厚、师兄师姐梯队完整，遇到问题有人接；代价是个人得到的关注被摊薄，选题可能被安排进大项目的一个模块。
- **小组**：老师亲自带、成长路径清晰、论文上署名靠前；代价是资源少、抗风险弱，老师风格不合时没有缓冲。

没有标准答案，只有和你的读研目的对齐：就业向、想在大平台镀金，大组的工程量和人脉有优势；深造向、想快速出属于自己的成果，小组的密度更划算。

## 用毕业去向做最终检验

导师主页的毕业生去向列表是最诚实的成绩单：你想走的路（大厂算法、国企、高校教职），他的学生有没有人走通过？走通的人大概用了几年、什么产出？如果没有人走通你想走的路，你要么说服自己改预期，要么换人——别假设自己是例外。

## 我的取舍记录

我选组时的排序就是按这个优先级走的：方向上锁定视觉感知与多模态（接得住我已有的检测、跟踪和多模态底子）；风格上我知道自己是「需要反馈节奏」的类型，组会频率和老师回复邮件的速度被我列为必查项——从我套磁期间和各位老师往来的回复速度与认真程度里，其实已经能读出一半答案；资源上确认了算力和项目情况；名气放在最后。这套过滤走完，剩下的候选人很少，纠结也少。

## 选择清单

- [ ] 每个候选导师标注：方向匹配（近三年论文）、指导风格（频率+放养度）、资源、毕业要求；
- [ ] 诚实回答「我属于需要反馈型还是自驱型」；
- [ ] 冲大组时问清「新生日常谁带」；
- [ ] 毕业去向里找到至少一个你想走的路径的成功先例；
- [ ] 排除掉任何一个「方向不匹配但其他都好」的选项。

方向和人选定下来，接下来就是把信发出去——进入 407 的套磁工作流。
