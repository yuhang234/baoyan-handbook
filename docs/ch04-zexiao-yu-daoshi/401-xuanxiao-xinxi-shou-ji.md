# 择校信息搜集指南

择校阶段最大的坑不是选错，而是「根本不知道有这个选项」。有人到 6 月才知道某校有深圳校区单独招生，有人不知道某个研究院也收推免生。信息差是保研里少数能靠勤快直接抹平的东西，这篇把渠道分三层讲清，最后给一张信息表的建法。

## 三层渠道

**第一层：官方渠道，用来定事实。** 学校研究生招生网、学院官网的通知公告、夏令营招生简章，是唯一可信的「规则来源」。招生人数、考核方式、报名截止时间、材料清单，都以这里为准。学院官网的师资页和教师个人主页，是后面套磁的主战场。官方渠道的缺点是只说规则不说体验，竞争激烈程度、真实录取门槛，它不会告诉你。

**第二层：经验贴与开源仓库，用来定水位。** 知乎、公众号上的保研经验贴，最有价值的部分是作者的个人背景（排名、本科层次、竞赛科研）和最终去向——这两行对起来，你就能大致校准「我这个背景能到哪一档」。读经验贴别只看上岸故事，重点看两段：开头「定位」怎么定的，结尾「决定」怎么做的。另外强推 CS-BAOYAN 这类开源保研仓库和它对应的交流群：仓库里有保研黑话解释、各校考核汇总、时间线通知，群里能看到同一届考生实时交换的入营和开奖信息。大三上就进去潜水，比 5 月再进友好得多。

**第三层：口碑渠道，用来定导师。** 学长学姐、在读师兄、导师评价网站。这一层信息主观性最强，用法见下一篇 405，这里只记一条原则：匿名评价只当弱参考，两个以上独立信源对上才算数。

## 经验贴怎么读才有用

- **找背景相近的。** 你的排名位次和本科层次，决定经验贴的参考价值。同样是去某校，专业第一和边缘位次的路径完全不同。
- **看失败的部分。** 写了自己在哪被拒、哪个环节踩坑的帖子，比一帆风顺的帖子信息密度高。
- **注意时效。** 两三年前的考核方式和名额结构可能已经变了，规则类的信息一定回官方渠道复核。

## 建一张自己的信息表

信息搜集的终点不是收藏夹，是一张表。建议从大三下开学就建，列名参考：

| 院校/学院 | 报名方式 | 材料要求 | 截止时间 | 考核方式 | 进度状态 | 备注 |
|---|---|---|---|---|---|---|
| | 系统/邮件 | | | 机试/面试/笔试 | 未报名/已报/入营/参营 | |

这张表在报名季就是你的作战地图：时间冲突一眼可见，材料缺口提前暴露。104 篇里提到的「入营通知和考核时间撞车」这类事故，都是靠这张表提前拦下来的。

## 发动身边的人脉

向直系学长学姐要三样东西：他们当年的去向、各校的门槛印象（bar 高不高）、考核内容印象。多数人愿意说，问的时候具体一点——「某校机试大概什么难度」比「某校好进吗」更容易得到有效回答。本校往届的去向分布，本身就是一份现成的定位参照。

## 检查清单

开始择校前，过一遍这张清单：

- [ ] 目标院校的招生简章和夏令营公告都从官网核实过原文；
- [ ] 读过至少五篇背景相近的经验贴，记录了各自的定位逻辑；
- [ ] 加入了保研交流群，看过开源仓库的黑话表和时间线；
- [ ] 建好了信息表，报名列、材料列、状态列齐全；
- [ ] 找两三位直系学长学姐问过 bar 和考核内容。

信息搜集做到这个程度，才轮到谈定位——那是下一篇的事。
