# 强 com 与弱 com

同样是「老师说要我」，在不同学校含义天差地别：有的地方这句话约等于录取，有的地方它只是一张入场券。差别背后的变量叫 com（committee）——录取话语权在学院委员会手里，还是在导师个人手里。搞不清这一点，你会把准备力气花在错误的地方。

## 定义与光谱

**强 com**：学院统一组织初审、考核、排序，按总分从高到低录取，录满即止。导师想收你，也得等你先拿到学院的「坑位」，之后才是师生双选。典型特征是机试、笔试占总分比重大，面试小组五七个人打分，而不是你未来的导师一人拍板。

**弱 com**：导师个人话语权大。导师认可你，学院流程基本是走程序。典型特征是招生公告里明确写「欢迎提前联系导师」，有的导师 3、4 月就开始通过带项目的方式考察人。

多数院系在两个极端之间，但总有明显偏向。判断不要靠道听途说，用下面两个办法。

## 怎么判断

**看考核公告。** 这是唯一可靠的公开证据：

- 公告写「机试 + 面试」「综合成绩 = 笔试 × X% + 面试 × Y%」「按总成绩排序录取」——强 com；
- 公告写「提前联系导师」「双向选择」「导师意向」——弱 com 或偏弱；
- 机试占比高、明确算法题范围——强 com 无疑。

**看经验帖的「决定」段。** 强 com 院校的经验帖会写「机试爆零就没了」，弱 com 的会写「导师点头后就稳了」。把目标院系的帖子各找几篇，看哪类抱怨出现得多。

## 强 com 的打法

强 com 的核心是：**初筛和总分决定一切，你的对手是考核体系本身。**

- **初筛关**：排名和本科层次是硬权重，亮点（论文、国奖竞赛）用来在边缘位次上拉差。简历按初筛逻辑写（参考 303）。
- **机试关**：机试是强 com 的生杀大权，算法题练熟比什么都强。以 CCF-CSP 300 分上下或 LeetCode 中等题稳定通过为基线，提前三个月练。
- **面试关**：专业课（数据结构、操作系统、计算机网络、机器学习）加英语口语，按题库准备（参考第五章面试篇）。
- **导师承诺的含金量**：在强 com 院系，「我要你了」的真实含义是「只要你能过学院初筛和考核，我就带你」。它可以当信心，不能当录取。该练的机试一题都不能少。

## 弱 com 的打法

弱 com 的核心是：**尽早锁定认可你的导师，考核只是流程。**

- **套磁要早**：热门导师的名额大三下学期就开始被预订，等夏令营公告出来再联系，多数时候只剩别人挑剩的方向。套磁工作流见 407。
- **导师的考察形式多样**：有的让你读论文、跑代码、做一个week-long 的任务。这是好事——考察越具体，说明他真的在挑人。接到任务就当正式面试准备。
- **拿到口头承诺后问清流程**：学院还剩哪些环节、有没有机试、什么时候双选。问清楚不是失礼，是防止把「导师同意」错当「录取到手」。

## 混合结构的特别提醒

不少院系是「强 com 拿坑位 + 弱 com 双选」的混合结构：学院统一考核发拟录取资格，但**最终去向取决于双选时有没有导师要你**。这种结构下，策略是两边都做：机试照练，同时提前联系意向导师——双选阶段没人接盘，拟录取也会作废。拿到优营的当晚就去问清后续流程（104 篇的教训），别自己脑补。

## 对策清单

- [ ] 目标院系逐个标注：强 com / 弱 com / 混合，依据是公告原文；
- [ ] 强 com 院系：机试训练计划落地，每天固定题量；
- [ ] 弱 com 院系：套磁名单排好批次，大三下学期发出第一批；
- [ ] 每个口头承诺后面，跟着一句「学院流程还有哪些环节」。
