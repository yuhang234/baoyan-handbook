# CS231N 100 问学习笔记

学 CS231N 的时候，我按「问答」的方式整理了 100 个核心问题，从 KNN 一路问到分布式训练。问答式整理有个好处：每个问题都是面试官可能问的形状，答题点想不全立刻暴露。这篇从 100 问里抽一条主线——视觉基础 → CNN 架构 → 训练细节——每题给最短的答案要点，当一份能快速过一遍的复习地图。

## 一、视觉基础

**Q：KNN 为什么不适合图像分类？L1 和 L2 距离对旋转的敏感性有何区别？**

要点：KNN 推理要和全部训练样本比距离，慢；图像在高维空间里「距离相近」不等于「语义相近」。L1 按坐标轴走，依赖坐标系，旋转会改变距离；L2 各向同性，对旋转不敏感。这也提示：特征本身比距离度量更根本。

**Q：为什么用验证集而不是测试集选超参数？**

要点：测试集必须模拟「没见过」。拿测试集调参等于把考卷泄露给自己，评估会乐观偏置。数据少就用 K 折交叉验证。

**Q：Softmax 和多类 SVM 损失的异同？**

要点：都是打分后算损失。SVM 用合页损失，只关心分数差过没过边界，「及格就行」；Softmax 交叉熵把分数变概率，永远鼓励把正确类的概率推向 1，追求「无限好」。调试时 Softmax 对分数尺度更敏感。

**Q：减均值、除标准差是为什么？**

要点：把输入拉到相近的尺度。收敛更快，损失面更规整；图像各通道量纲相同，通常只减均值即可。

## 二、CNN 架构

**Q：卷积的输出尺寸怎么算？Stride 和 Padding 各起什么作用？**

要点：输出 = (输入 + 2×Padding − 卷积核) / Stride + 1。Stride 下采样降分辨率，Padding 保住空间尺寸、减少边缘信息损失。

**Q：为什么 VGG 用两层 3×3 卷积替代一层 7×7？**

要点：两层 3×3 的感受野等于一层 7×7，但参数从 49C² 降到 18C²，还多了一次非线性。这就是「小卷积核堆叠」的账。

**Q：网络加深反而错误率升高，为什么？ResNet 怎么解决？**

要点：这不是过拟合（训练集也变差），是退化——深网络难以优化。ResNet 加恒等映射的跳跃连接，网络只需学「增量」F(x)，最差也能退化回浅层等价，梯度经捷径直达浅层，百层千层都能训。

**Q：两阶段和单阶段目标检测的区别？**

要点：两阶段（R-CNN 系列）先由 RPN 出候选框再精修，准但慢；单阶段（YOLO）一次前向直接出框和类别，快，适合实时。DETR 再进一步，用 Transformer 的 Object Queries 把检测变成集合预测，去掉手工设计的候选机制。

**Q：ViT 怎么把图像变成 Transformer 的输入？**

要点：切成固定大小的 patch，每个 patch 展平后线性投影成 token，加上位置编码；再加一个可学习的 [CLS] token 汇总全局信息做分类。ViT 的归纳偏置比 CNN 弱，所以大数据预训练下才反超。

## 三、训练细节

**Q：为什么必须有非线性激活函数？**

要点：不加的话，多层线性变换叠起来还是线性变换，网络再深也只有线性表达能力。ReLU 最常用：计算便宜，正区间梯度恒为 1，缓解梯度消失。

**Q：Sigmoid 为什么引发梯度消失？**

要点：两端饱和区导数趋近 0，反向传播乘过去层层衰减，深层网络浅层几乎收不到有效梯度。ReLU 及其变体、合理的初始化都是围绕这个问题的解。

**Q：BatchNorm 和 LayerNorm 的区别？**

要点：BatchNorm 沿 batch 维算统计量，训练时要维护移动平均，依赖批大小；LayerNorm 沿特征维算，单样本即可，不依赖 batch——所以 Transformer 全用 LayerNorm。

**Q：Momentum 的物理直觉是什么？**

要点：给优化加惯性。速度是历史梯度的指数加权平均，来回震荡的分量互相抵消，一致方向被累积，还能帮优化逃离鞍点和小的局部极小。RMSProp/Adam 再按梯度的历史尺度自适应调学习率，Adam 训练初期要做偏差校正，因为零初始化的动量估计偏小。

**Q：Dropout 训练和测试阶段有什么不同？**

要点：训练时随机置零一部分神经元等效于训练子网络的集成；测试时不丢弃，但输出要按保留概率缩放（或训练时用 inverted dropout 预先缩放），保证期望一致。

**Q：Kaiming 初始化在解决什么？**

要点：如果初始化方差不对，信号逐层放大或衰减，激活和梯度都会爆炸/消失。Kaiming 针对 ReLU（一半神经元输出为零）把权重方差设为 2/n_in，让每层激活的方差保持稳定。
