# 算法模板刷题路线

保研机试和蓝桥杯这类比赛，考的绝大多数不是灵机一动，是模板的熟练度：DFS、BFS、二分、前缀和、背包、最短路，每一个都有固定写法，练熟就能拿分。所以刷题路线比刷题量重要。这篇给一条「模板题先行」的四轮路线，题源按 AcWing → 洛谷 → 牛客 分工。

## 三个平台的分工

- **AcWing**：模板题的教科书。题号和知识点一一对应，讲过什么就考什么，用来把每个模板第一次写对。
- **洛谷**：同知识点的「正式比赛题」。同样是并查集、单调栈，这里的题多了一层建模，用来检验你是不是真懂了，还是只是背下来了。
- **牛客**：补细节和输入输出格式。机试和某些比赛用牛客系平台，「模板」系列的题集中，适合考前适应题型。

顺序别反。先在 AcWing 把模板写熟，再上洛谷做变形，最后用牛客查漏——直接一上来刷洛谷，很容易被劝退。

## 四轮刷题法

**第一轮：基础模板。**DFS、BFS、二分、前缀和、差分、单调栈、单调队列、并查集。

**第二轮：DP。**数字三角形、LIS、LCS、01 背包、完全背包、多重背包。

**第三轮：图论。**Dijkstra、SPFA、Floyd、Prim、Kruskal、LCA。

**第四轮：字符串和数论。**KMP、Trie、字符串哈希、快速幂、筛质数、扩展欧几里得。

每轮的具体题单，我按「AcWing 模板题 → 洛谷对应题」整理过一份，举几个锚点：

| 知识点 | AcWing 模板 | 洛谷对应 |
|---|---|---|
| DFS / N 皇后 | 843 | P1219 |
| BFS / 走迷宫 | 844 | P1443 |
| 前缀和 | 795 | （牛客【模板】前缀和） |
| LIS | 895 / 896（二分优化） | P1020 |
| 01 背包 | 2 | P1048 |
| Dijkstra | 849 / 850（堆优化） | P4779 |
| KMP | 831 | P3375 |
| 快速幂 | 875 | P1226 |

一张同款对照表可以覆盖第一到第四轮的全部知识点，做法就是照着这个模式把每个知识点填进三列。

## 每道题的写法要求

模板训练有个坑：看题解觉得自己会了。我的要求是三条：

1. **每个模板至少独立默写一遍。**不看任何资料，从空文件写到 AC。写不出来就说明还没会。
2. **变形题先想「它改了模板的哪一步」。**洛谷的题基本都是在模板上动一处：输入规模、方向、初始化。定位到那一处，比重新想一遍快得多。
3. **错题记「错在哪一步」，不记「这题的解法」。**比如「二分边界又写错了，循环条件应该是 l < r 还是 l <= r」——错题本记的是模板的易碎点，不是题目本身。

## 别忘了目标要具体

最后说一个教训。去年我准备蓝桥杯的时候，给自己定的目标是「拿个奖」——这种模糊目标的结果就是练练停停。后来干脆写死「就要省一，还剩十天，其余的事都往后排」，节奏立刻不一样了。人的大脑特别不喜欢模糊：目标越具体，每天该干什么就越没有商量余地。

我的做法是把目标换算成题量倒推：十个知识点 × 每个默写一遍加两道变形，就是三十道题的量，平摊到每天是几道，一目了然。十天后省一到手，靠的不是爆发，是把模糊的「要练算法」变成了一张填好的表。

这条路线对保研机试同样适用：机试考的模板集合就是这四轮的前两轮多一点，时间紧的话优先刷完第一、二轮，图论挑 Dijkstra 和并查集，字符串和数论可以战略性放弃。
