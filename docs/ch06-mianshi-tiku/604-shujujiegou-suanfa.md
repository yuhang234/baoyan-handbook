# 数据结构与算法面试题

数据结构是计算机专业课面试的第一站，题量最大、追问最深。好消息是高频题高度收敛：复杂度分析、链表数组对比、树的演进链、图的四大算法、排序对比表、哈希原理——每个模块就几个核心题。这篇按模块给出「问题 → 骨架 → 追问 → 失分点」，先保口述题，机试见 611。

## 复杂度分析：一切追问的起点

**主问题：什么是时间复杂度和空间复杂度？常用级别有哪些？**

骨架：衡量运行时间随规模增长的趋势 → 只保留最高阶、忽略常数和低阶 → 级别从优到劣：O(1)、O(logn)、O(n)、O(nlogn)、O(n²)、O(2ⁿ) → 空间复杂度看辅助空间，不含输入输出。

追问与陷阱：递归的复杂度怎么算——时间拆「层数 × 每层操作」，空间看递归栈深度（斐波那契普通递归是 O(2ⁿ) 时间 O(n) 空间，重复计算是题眼）；为什么可以忽略常数——大 O 管的是大规模下的增长趋势，面试默认用最坏复杂度，因为它保证性能上限。

失分点：把「复杂度低」说成「一定更快」，n 小的时候常数项主导，O(n²) 可能比 O(nlogn) 快。

## 线性表：数组、链表、栈队列

**数组 vs 链表。** 骨架：数组连续内存、随机访问 O(1)、增删要移动 O(n)；链表指针连接、查找 O(n)、增删改指针 O(1) → 选型：多查询用数组，多增删用链表。追问为什么链表不支持随机访问——节点地址不连续，无法用下标偏移定位，这是底层原因，必须答出「地址不连续」四个字。

**两个栈实现队列。** 骨架：入栈全进 A → 出栈时 A 倒入 B，从 B 弹 → B 非空时直接弹。追问摊还复杂度：每个元素最多进栈出栈各两次，均摊 O(1)。

**循环队列判空判满。** 骨架：空是 front == rear；满牺牲一个格（rear+1)%N == front，或另设 size 计数。失分点：不牺牲格子的话空和满条件重合，这题考的就是这个矛盾。

**链表有环怎么判。** 骨架：快慢指针，快一次两步慢一步，相遇则有环 → 找入口：相遇后一指针回头，两指针同速前进，再相遇即入口（数学推导可现场推一遍）。反转链表要能当场手写，迭代版三指针。

## 树：从 BST 到 B+ 树的演进链

这一串题最好按「演进逻辑」串起来讲，比散着背高一档：

**BST → AVL → 红黑树。** 骨架：BST 左小右大、中序有序，最坏退化成链 O(n) → AVL 严格平衡（高度差 ≤1），查询稳 O(logn)，但插删旋转多 → 红黑树近似平衡，用五条性质换取插删少旋转，工程更常用（HashMap 的选择及理由是高频追问）。

**B 树与 B+ 树。** 骨架：多路平衡树，矮胖，减少磁盘 I/O → B+ 树数据全在叶子且叶子成链，范围查询快、非叶节点只存索引扇出更大 → 为什么数据库索引用它：磁盘页 + 范围查询 + 矮树，三个理由缺一不可。

**堆。** 骨架：完全二叉树 + 父子序关系 → 建堆 O(n)（自底向上下沉，不是 O(nlogn)，高频陷阱）→ 插入删除 O(logn) → 应用：优先队列、TopK、堆排序。

**遍历与还原。** 骨架：前中后序 + 层序 → 前序 + 中序可唯一还原（前序定位根、中序分左右），后序 + 中序同理，前序 + 后序不能（无法区分单子树）。失分点：说不出「为什么必须含中序」。

## 图：四大算法一张表

**存储**：邻接矩阵 O(V²) 空间、查边 O(1)，适合稠密图；邻接表 O(V+E)，适合稀疏图。

**最小生成树**：Prim 从点出发 grows 一棵树，适合稠密图；Kruskal 排边 + 并查集，适合稀疏图。

**最短路径**：Dijkstra 单源、非负权、贪心 + 优先队列 O((V+E)logV)；Bellman-Ford 允许负权、能检负环；Floyd 多源、DP、O(V³)。追问三者适用场景对比是最爱考的收尾。

**拓扑排序**：Kahn 队列法或 DFS 逆序，只对有向无环图成立 → 应用：任务调度、编译依赖。追问：怎么判断图里有环——拓扑排序排不完所有点。

## 排序：一张对比表 + 三个深挖点

把十大排序的「平均/最坏复杂度、空间、稳定性」做成一张表背熟，这是本模块的地基。表之上的追问：

**快排**：平均 O(nlogn)、最坏 O(n²)（有序数组 + 固定基准）→ 优化：随机基准、三数取中、小区间换插入排序。手写快排必须过关，partition 写不利索的每年都有。

**稳定性**：稳定的有插入、冒泡、归并、计数、基数；不稳定的是选择、快排、希尔、堆排。追问稳定性的实际意义——多关键字排序时先按次关键字排再按主关键字稳定排。

**外部排序**：数据放不进内存 → 分块内排 + 多路归并，败者树优化归并路数。

## 查找与算法设计

**哈希表**：哈希函数 → 冲突解决：链地址法（Java 8 后长链转红黑树是加分点）、开放定址（线性探测、二次探测）→ 负载因子触发扩容 rehash。追问为什么查询是 O(1) 还要树结构——哈希无序、不支持范围查询，最坏退化 O(n)。

**动态规划 vs 贪心**：DP 适用条件是最优子结构 + 重叠子问题，贪心要求局部最优可推全局最优且不一定成立——「贪心不一定对」这句话本身就是考点。经典题备三道：0-1 背包（状态定义和转移方程要能口述）、最长公共子序列、最大子段和。

**手写题清单**：快排、二分查找（边界！）、链表反转、归并。练到白纸默写无 bug，机试和面试两用。

最后一条经验：口述题的答案要练到 90 秒说完骨架，先结构后细节；老师要的是「你知道这东西为什么这样设计」，不是背诵。
