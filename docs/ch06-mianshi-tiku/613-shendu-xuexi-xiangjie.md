# 深度学习面试问题详解

612 答「是什么」，这篇答「为什么」。面试官喜欢顺链追问：激活函数 → 梯度消失 → BN → 残差 → Transformer → 大模型，每层断在哪一眼就能看出来。按五层给机制级的骨架。

## 基础概念

**神经网络与激活函数。** 骨架：神经元 = 线性变换加非线性激活 → 没有激活函数，多层等价于单层（矩阵连乘还是线性）→ 四个常用：Sigmoid 输出 (0,1) 但饱和区梯度趋零；Tanh 零中心仍会饱和；ReLU 正区间梯度恒 1；Softmax 把 logits 归一成概率分布放在输出层。

**ReLU 为什么比 Sigmoid 好。** 骨架三点：正区间梯度恒定不消失；计算只要一次比较；稀疏激活。追问缺点——负区间梯度为零，神经元死亡；改进：Leaky ReLU、ELU、GELU。这张对比表要能脱口而出。

**前向与反向传播。** 骨架：前向算输出和损失 → 反向用链式法则从输出层逐层回传梯度 → 本质是链式法则的高效实现，每层只用相邻层的梯度，不重复计算。能现场推两层网络的链式求导是硬通货。

**梯度消失与爆炸。** 骨架：深层梯度连乘导致指数衰减或放大 → 消失：浅层几乎不更新；爆炸：loss 变 NaN。方案清单六条：换激活函数、合理初始化（Xavier/He）、BatchNorm、残差连接、梯度裁剪（治爆炸）、LSTM 门控（治 RNN）。这题骨架词几乎每年都考，背熟。

**BatchNorm。** 骨架：对每个 mini-batch 按通道归一化，再学习缩放平移参数 γ、β → 效果：稳定每层输入分布，允许更大学习率，轻微正则。追问三条：训练用 batch 统计、推理用滑动平均；小 batch 效果差；标准顺序是卷积 → BN → 激活。

**Dropout。** 骨架：训练时以概率 p 随机置零神经元，推理保留全部并补偿 → 原理两层：每次训练一个不同子网络相当于集成；逼网络不依赖单个神经元。追问训练和推理行为差异，答不清直接扣分。

## CNN

**三件套分工。** 骨架：卷积——局部连接加权值共享，参数量大降；池化——下采样，增大感受野，带来平移不变；全连接——把特征映射到类别。追问为什么适合图像——空间局部性先验。

**感受野。** 骨架：一个神经元能看到的输入区域 → 加深、池化、大卷积核都增大它 → 设计逻辑：后层需要大感受野看全局。

**1×1 卷积。** 骨架：通道维的线性组合 → 三个作用：升降维、跨通道融合、Bottleneck 省参数。小题，但答不出很伤。

**ResNet。** 骨架：恒等捷径让网络学残差 F(x)=H(x)−x → 为什么有效：梯度经捷径直接回传，深层网络退化有出口。注意表述：它解决的不只是梯度消失，是「加深反而变差」的退化问题——这句说对了就是加分项。追问为什么两层一块做残差：两层才有非线性变换的余地，一层的话恒等映射学起来没有收益。

## 序列模型

**RNN 的困境。** 骨架：逐步递推，长序列梯度消失或爆炸 → 记不住远处信息。

**LSTM。** 骨架：三门加细胞状态——遗忘门决定丢什么，输入门决定存什么，输出门决定给什么 → 细胞状态是加法高速公路，梯度经它长距离流动。GRU 是两门的简化版，效果接近参数更少。

**Attention。** 骨架：查询和键算相似度 → softmax 得权重 → 对值加权求和 → 解决 RNN 把整句压成固定向量的信息瓶颈。

**Transformer。** 骨架：自注意力加多头加位置编码加残差和 FFN → 相比 RNN 三优势：并行训练、任意距离一步直达、多头捕捉多种关系。两个必考追问：为什么需要位置编码——自注意力本身对顺序无感；缩放点积为什么除以 √d——维度大时点积方差大，softmax 会饱和，梯度就没了。

## 训练与生成

**损失函数。** 骨架：分类交叉熵、回归 MSE/MAE → 分类为什么不用 MSE：非凸且梯度被激活函数导数拖累，这是和 612 逻辑回归一题的两面。

**过拟合排查。** 骨架：看训练验证曲线——双双偏高是欠拟合，加容量；明显分叉是过拟合，加数据加正则；两个都不降，先查数据、标签和学习率，最后才怪模型。

**GAN。** 骨架：生成器造假、判别器打假，对抗到平衡 → 失分点：只会说「一个生成一个判别」，说不出对抗在损失上怎么体现。追问训练不稳定和模式坍塌，知道词就答词。

**VAE 与自编码器。** 骨架：AE 只学重建，隐空间不连续，不能采样 → VAE 编码到分布而非点，重参数化让采样可导，损失里加 KL 项 → 隐空间能生成。三者是一根演进链，按链讲最省力。

---

这五层的顺序不是随便排的：它就是面试官追问的典型路径。练法是自问自答——从「ReLU 为什么好」出发，看自己能不能自然走到 Transformer 和大模型，中间断掉的地方就是你没真懂的地方。
