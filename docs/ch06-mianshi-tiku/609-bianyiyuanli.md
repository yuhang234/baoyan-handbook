# 编译原理面试题

编译原理是专业课面试里的差异化科目：问的人少，但一旦问起，答上来的人更少。它常以两种面貌出现——要么直接问「编译分几个阶段」，要么化整为零藏在角落（「DFA 和 NFA 什么区别」「编译器和解释器差在哪」）。备好六个模块的骨架，这门课就能从失分项变成加分项。

## 编译的完整流程：全局框架题

**主问题：编译过程分为哪几个阶段？**

骨架：词法分析（字符流 → 单词流）→ 语法分析（单词流 → 语法树）→ 语义分析（类型检查、符号表登记）→ 中间代码生成 → 代码优化 → 目标代码生成 → 贯穿全程的是符号表和错误处理两个辅助模块。

追问与陷阱：哪些阶段与机器相关、哪些无关——前端（词法、语法、语义、中间代码）与机器无关，后端（目标代码生成）与机器相关，优化的位置决定了编译器的移植性；「解释器走哪条路」——解释器不生成目标代码，逐句解释执行，这个对比放到最后一节展开。

失分点：六个阶段说成五个或七个且名目混乱——这是纯记忆题，顺序错了直接暴露没复习。

## 词法分析：DFA 与 NFA

**主问题：词法分析做什么？正则表达式、DFA、NFA 什么关系？**

骨架：词法分析把字符流切成记号（标识符、常数、运算符、界符），靠模式匹配完成 → 描述模式用正则表达式 → 机器实现用有穷自动机：NFA 允许多个后继和空转移，DFA 每个状态对每个输入只有唯一后继 → 转换链：正则式 → NFA（机械构造）→ 子集法确定化 → DFA 最小化（合并等价状态）。

追问与陷阱：DFA 和 NFA 的表达能力谁强——等价，任何 NFA 都能确定化为 DFA，能识别的语言类相同，区别只在构造难易和状态数；「为什么实际用 DFA」——查表执行、速度确定性，NFA 只是中间形式。DFA 最小化的意义也要会说：减少状态数，让识别器更省更快的理论保证。

失分点：把「NFA 表达能力强于 DFA」当结论——这是本模块最经典的陷阱，考的就是你知不知道二者等价。

## 语法分析：自顶向下与自底向上

**主问题：语法分析的方法有哪些？LL 和 LR 什么区别？**

骨架：任务是按文法规则把记号流组织成语法树 → 自顶向下：从根出发推导，代表是递归下降和 LL(1)——要求消除左递归、提取左公因子，FIRST/FOLLOW 集构造预测分析表 → 自底向上：从叶子归约到根，代表是 LR 家族（LR(0)、SLR、LALR、LR(1)，归约能力逐级增强）→ 一句话对比：LL 从左到右最左推导，LR 从左到右最右推导的逆过程，LR 能处理的文法更广、实现更复杂。

追问与陷阱：什么是左递归、为什么 LL(1) 不能处理它——推导永不终止，必须改写；算符优先分析法——只看终结符之间的优先关系做归约，实现快但覆盖窄；二义性文法怎么处理——改写文法或附加优先级/结合性声明。

这一模块最容易被打断追问 FIRST 集、FOLLOW 集怎么求。FIRST 是从左端能推出的终结符集合，FOLLOW 是句型中可能跟在非终结符后面的终结符集合，定义要背准，老师爱让现场对一个简单文法求一遍。

## 中间代码与优化

**中间代码**：骨架：位于语法树和目标代码之间的过渡表示 → 常见形式：三地址码（x = y op z）、四元式、逆波兰式（后缀表达式）→ 作用：让前端与目标机解耦，优化在统一的中间表示上做，一处优化多平台受益。

追问：逆波兰式怎么求——手工转换用运算符栈（调度场算法思想），问「a+b*c 的后缀式」这类小题要能秒答（abc*+）。

**代码优化**：骨架按位置分局部优化（基本块内：合并常量、删除公共子表达式、消除死代码）与全局优化（跨基本块：循环不变代码外提是代表）→ 不改变程序语义是优化的前提，这句话要主动说。

**符号表**：骨架：登记标识符的属性（类型、作用域、地址）→ 语义分析和代码生成都在查它 → 追问作用域处理——嵌套作用域用栈式符号表，进入作用域压栈、退出弹出。

## 编译器 vs 解释器：收尾对比题

**主问题：编译器和解释器的区别？**

骨架：编译器整体翻译生成目标程序，执行时不再需要源程序和编译器，快、可分发，C/C++ 路线 → 解释器逐句读取解释执行，边解释边运行，慢但灵活、跨平台（一次解释处处运行），Python 路线 → 中间形态：Java 先编译成字节码再由 JVM 解释/JIT 执行，混合路线最能体现理解。

追问：为什么脚本语言开发效率高、C 程序跑得快——把「翻译时机」和「运行时开销」两条线说清，这题就算答透了。

## 复习取舍

编译原理在多数面试里只占一两问，投入产出比要把关：优先备「编译阶段」「DFA/NFA」「LL vs LR」「编译器 vs 解释器」四道主问题，每道练到 90 秒骨架版；FIRST/FOLLOW 的现场求解和逆波兰式转换各练两个小例题防手写追问。文法的形式化定义、属性文法这类深水区，除非明确被问，不必主动跳进去。
