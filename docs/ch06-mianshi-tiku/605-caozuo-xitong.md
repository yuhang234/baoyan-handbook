# 操作系统面试题

操作系统在面试里的地位仅次于数据结构，而且最爱考「区别与联系」类对比题。这篇按六大块整理：进程线程、通信与同步、调度、死锁、内存、中断与内核。

## 进程与线程：必考第一题

**主问题：进程和线程的区别与联系？**

骨架：进程是资源分配的最小单位，线程是 CPU 调度的最小单位 → 线程共享进程的堆、全局变量、打开文件，私有自己的栈和寄存器 → 进程间独立、隔离性好、切换开销大；线程共享、通信方便、一个崩全崩 → 选型：要隔离稳定用多进程（浏览器每标签一个进程），要高并发低开销用多线程。

追问与陷阱：为什么进程切换比线程慢——要换页表、刷 TLB 和缓存，线程共享地址空间只存私有上下文；并发和并行的区别——宏观交替 vs 硬件同刻；协程——用户态调度的轻量执行单元，切换不进内核，这是近年新宠追问。

失分点：把「线程是轻量级进程」当答案说完就停，没有共享/私有资源的具体划分。

## 进程通信与同步互斥

**IPC 方式**：骨架：管道（亲缘进程、半双工）、消息队列（有格式、可按类型取）、共享内存（最快，需配信号量同步）、信号（异步通知）、套接字（跨主机）→ 共享内存为什么快：数据零拷贝，其余方式都要经内核中转。

**经典同步问题**：生产者-消费者（两个信号量：空槽、满槽 + 一个互斥锁，P 操作顺序不能错否则死锁）、读者-写者（读者计数 + 写者优先级问题）、哲学家进餐（解法：奇偶号拿叉顺序不同，或一次拿齐）。这三个不用背代码，但要能讲清信号量怎么设、谁先谁后。

**锁**：互斥锁、自旋锁（忙等，临界区短才划算）、读写锁的区别与适用场景。

## 调度与死锁

**调度算法**：FCFS 简单但对短作业不公；SJF 平均等待最短但长作业饥饿；RR 时间片轮转保公平，片太短切换开销大、太长退化 FCFS；多级反馈队列是集大成者——不用人工设优先级，行为自动分层。追问：时间片大小怎么权衡，答两端退化即可。

**死锁**：四个必要条件一个不能少——互斥、请求与保持、不剥夺、环路等待 → 破坏任意一个即可预防：资源一次性申请、有序分配破坏环路等待 → 避免用银行家算法（分配前判断系统是否仍在安全状态）→ 检测用资源分配图找环。

追问与陷阱：死锁、饥饿、阻塞三者区别——阻塞是正常等待，饥饿是调度不公导致长期得不到执行，死锁是互相等待的永久阻塞；哲学家进餐问题就是死锁的活教材，两题可以串着答。

失分点：四条件背得出但给不出对应的破坏策略，白背。

## 内存管理：虚拟内存是核心

**虚拟内存**：骨架：每个进程一个独立虚拟地址空间 → 页表映射到物理内存 → 好处：隔离、内存超售（换页）、方便共享。追问缺页中断的处理流程：查页表发现不在内存 → 缺页异常 → 选页淘汰（可能写回）→ 调入 → 更新页表重执行指令。

**页面置换算法**：FIFO 有 Belady 异常（帧越多缺页反而可能越多，加分点）；LRU 按访问时间淘汰、硬件实现贵，工程上用 Clock 近似；OPT 理论最优但不可实现，用作评测基准。

**分页 vs 分段**：分页固定大小、为内存利用率服务、对用户透明；分段按逻辑模块、大小可变、便于共享和保护 → 段页式取两者之长。这道对比题的答题关键是分清「谁的视角」。

**快表 TLB**：页表项的缓存，命中则省一次内存访问，靠局部性原理撑命中率。

## 内核态、中断与 I/O

**用户态/内核态**：为什么区分——保护内核数据结构和硬件，不让应用乱来 → 切换时机：系统调用、中断、异常。追问系统调用过程：传参 → 陷入 trap → 内核执行 → 返回，强调「陷入」这个词。

**中断 vs 异常**：中断来自外设、异步；异常来自指令执行、同步。

**DMA**：外设和内存直传、不经 CPU，CPU 只在初始化和结束时参与 → 和中断方式对比：成批传输时 CPU 占用大幅下降。

**零星高频**：僵尸进程（子进程退出父进程没 wait，杀父进程可清）与孤儿进程（父先走，被 init 收养，无害）；inode（文件元数据，文件名只是它的别名，硬链接就是多个名字指向同一 inode）；磁盘调度 SCAN 电梯算法。

复习建议：这一科追问链条短、术语密，适合集中突击。每块先把对比题的「两边定义」说准，再背各自的应用场景——面试官判断你是真懂还是背书，就看场景给不给得出来。
