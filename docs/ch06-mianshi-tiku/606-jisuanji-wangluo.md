# 计算机网络面试题

网络面试题的重心极其集中：应用层抓 HTTP/HTTPS，传输层抓 TCP，剩下的都是这两块的铺垫和延伸。复习时把七成的力气放在 TCP 三次握手、可靠传输和 HTTPS 加密流程上，性价比最高。

## 分层模型：先立框架再填内容

**OSI 七层 vs TCP/IP 四层。** 骨架：OSI 从上到下应用、表示、会话、传输、网络、数据链路、物理；TCP/IP 是应用、传输、网络接口（把下三层合一）→ 每层挑两个代表设备或协议说一句。追问为什么分层——大问题切小、层间接口稳定则各层可独立演进、故障定位到层。三个理由里「独立演进」最能体现理解。

**三个地址一条线**：域名（应用层，给人看）→ IP（网络层，定位主机）→ MAC（链路层，定位网卡）。转换关系：DNS 域名转 IP，ARP 用广播问「谁有这个 IP」拿 MAC。这条链是很多综合题的骨架。

## TCP 与 UDP：重中之重

**主问题：TCP 和 UDP 的区别？**

骨架：TCP 面向连接、可靠、字节流、头部 20 字节起；UDP 无连接、尽最大努力交付、报文保留边界、头部 8 字节 → 场景：文件传输、网页用 TCP；直播、游戏、DNS 用 UDP → 收尾一句：选型本质是「可靠性」和「实时性」谁让路。

**三次握手。** 骨架：SYN（seq=x）→ SYN+ACK（seq=y, ack=x+1）→ ACK（ack=y+1）→ 为什么不是两次：两次无法确认客户端的接收能力，服务端会为失效的连接请求白开端口浪费资源；历史 SYN 到达的旧连接问题也防住。追问三次握手能带数据吗——第三次可以，前两次不行（防止 SYN 洪泛携带大包攻击）。

**四次挥手。** 骨架：FIN → ACK → FIN → ACK，各方向的发送通道独立关闭所以是四次 → TIME_WAIT 等待 2MSL：保证最后一个 ACK 若丢失对方重发的 FIN 还能被处理，并让旧报文在网络中自然消亡。追问服务端大量 TIME_WAIT 怎么办（连接复用、长连接）。

**可靠传输**：骨架：序号 + 确认应答 → 超时重传 → 滑动窗口做流量控制（接收方通告窗口）→ 拥塞控制四个阶段：慢启动指数涨、到阈值转拥塞避免线性涨、丢包后快重传（三个冗余 ACK）+ 快恢复。追问流量控制和拥塞控制的区别——前者保护接收端（端到端），后者保护网络（全局），这是最爱考的对比。

失分点：把「TCP 可靠」答成「不会丢包」。网络会丢包，TCP 靠重传把丢包补救回来——「检测丢失并恢复」和「保证不丢」是两回事。

## HTTP 与 HTTPS

**HTTP 演进**：1.0 短连接 → 1.1 长连接（keep-alive）、管道化 → 2.0 二进制分帧、多路复用、头部压缩 → 3.0 换 QUIC、基于 UDP。每代解决上一代什么问题，这条线讲清楚是加分项。

**常见状态码**：200 成功、301 永久重定向、302 临时、304 协商缓存命中、403 禁止、404 未找到、500 服务器内部错误、502 网关收到无效响应。

**GET vs POST**：语义（获取 vs 提交）、参数位置（URL vs 请求体）、幂等性、缓存——答全四点，只答参数位置是不及格的。

**HTTPS 加密流程**：骨架：TCP 握手之后 TLS 握手 → 协商加密套件 → 服务器出示证书（CA 签名验证身份）→ 客户端生成对称密钥，用服务器公钥加密传过去 → 之后全部用对称加密通信 → 为什么混合：非对称安全但慢，只用来护送密钥；对称快，用来跑业务数据。追问证书怎么验证：CA 链逐级验签 + 有效期 + 域名匹配。

**Cookie vs Session**：Cookie 存客户端、随请求携带、有大小限制；Session 存服务端、靠 Cookie 里的 SessionID 关联。

## 综合题：输入 URL 之后

**「从输入 URL 到页面显示发生了什么」**是网络面试的万能综合题，把所有知识点串成一条线：

1. DNS 解析：浏览器缓存 → 系统缓存 → 本地 DNS → 根、顶级、权威逐级查（递归 + 迭代）；
2. TCP 三次握手（HTTPS 再加 TLS 握手）；
3. 发送 HTTP 请求，服务器处理后返回响应；
4. 浏览器解析 HTML 构建 DOM 树、CSSOM，渲染页面；
5. 四次挥手断开（或保持长连接）。

答这题的策略是按层报幕，每层主动说一句关键的（如「这里走的是 UDP 的 DNS」），给老师递追问点——追问点在你手里，比被随机抽问强。

**零星高频**：DNS 为什么用 UDP——查询短小快、失败可重试，区域传送才用 TCP；ARP 工作过程（同网段广播、跨网段问网关）；交换机（链路层、按 MAC 转发）与路由器（网络层、按 IP 路由）；IPv6 为什么出现——地址耗尽一条就够，顺带说简化头部和自动配置。

网络的答题风格和操作系统一样：先把「区别类」的双方定义说准，再用场景收尾。老师几乎必然从你的答案里挑一个词继续追，所以每个名词都要经得起一层「为什么」。
