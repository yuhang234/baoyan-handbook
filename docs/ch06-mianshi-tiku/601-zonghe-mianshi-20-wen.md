# 综合面试高频 20 问

综合面试的题池其实很小，翻来覆去就是那二十来个问题。差别在于：有人照着问题背答案，答出来像朗读；有人按骨架准备，答出来像说话。这篇把高频题按组拆开，每组给答题骨架、追问和失分点。骨架里的关键词建议背下来，正文用嘴组织。

## 自我介绍：1 分钟和 3 分钟不是剪裁关系

**问题：请做一个自我介绍。**

骨架：一句话定位（学校、排名、方向）→ 两三个硬证据（排名 7/330、一篇在稿论文、一个完整项目）→ 与对方方向的连接点 → 收一句为什么来这里。

追问与陷阱：老师会从你介绍里挑一个词往下追，你说的每个名词都是自愿递出去的提问权。介绍里出现的项目、课程、竞赛，必须每个都能撑住两层追问。

失分点：1 分钟版是 3 分钟版的缩写，但重点不同——1 分钟版只留硬证据，3 分钟版才铺经历线。背得太满、塞满形容词（「勤奋努力踏实」）而无证据，是最低级的失分。

## 动机三连：为什么读研、选我们、选方向

**问题：你为什么想读研究生？为什么选择我们学校？为什么选这个方向？**

这三题要分开准备，但共享一个原则：答案必须长在你自己的经历上。

骨架（读研动机）：具体触发事件（某个项目做到一半发现只会用不会懂）→ 对某类问题的持续兴趣 → 读研是解决它的必要条件。骨架（选学校）：读过对方课题组的工作，说出一两个具体方向或论文标题 → 和自己做的东西的衔接点。骨架（选方向）：从做过的项目自然延伸，而不是「前景好」「感兴趣」三个字打发。

追问与陷阱：「你还投了哪些学校？都录取了选哪个？」——这是动机题的变体。策略是承认投了多家（撒谎会穿帮），但给出只属于这一家的理由，且理由要具体到方向和课题组的某项工作。

失分点：夸学校只夸「学术氛围浓厚、师资力量雄厚」，等于没说；说不出对方课题组任何具体工作，「为什么选我们」就直接挂了。

## 规划题：硕士计划和读博态度

**问题：你未来有什么规划？读博吗？第一学期打算怎么安排？**

骨架：硕士第一年打基础（课程 + 读文献 + 复现）→ 二三年出工作 → 读博表态给明确倾向并说理由，无论倾向哪边。报直博的同学规划要讲到博士层面，拿硕士话术讲会露怯。

追问与陷阱：说想读博，会追「为什么」；说不想读博，有的老师会追「那你觉得硕士三年够干什么」。两头都要有说法，且前后一致——一面说立志科研，一面规划里写毕业进大厂，这种矛盾很容易被抓住。

失分点：规划全是空话（「好好跟导师做科研」），没有一个可检查的动作。

## 个人特质题：优缺点、困难、成就感

**问题：你最大的优点和缺点是什么？你遇到过最大的困难是什么？最有成就感的事是什么？**

骨架（优缺点）：优点配一个实例（「能坐得住」→ 论文改投期间逐条回复审稿意见的经历）；缺点说真实但不致命的，并给出正在用的补救动作。骨架（困难题）：用 STAR 结构——情境、任务、行动、结果，落点放在「行动」上。

追问与陷阱：困难题会追「最后彻底解决了吗」。准备一个真实结局：有的解决了，有的靠换方法绕过去了，绕过去也是合理答案。缺点题最怕追「你说你粗心，那你论文里的数据怎么保证对的」——缺点和你的工作不能自相矛盾。

失分点：把缺点包装成优点（「我最大的缺点是太追求完美」），老师听得出来，印象反而减分；困难题选「考试没考好」这类没有行动空间的事。

## 硬问题：成绩、英语、竞赛

**问题：你的 GPA 和排名是多少？为什么有的课程成绩不高？四六级多少分？**

骨架：排名直接报（7/330），不绕弯。低分课准备一两门，理由给过程性的（那学期同时在赶某个项目/竞赛的节点），不甩锅给老师。六级分数不高就立刻接一句补救证据：能流畅读英文文献、论文就是用英文写的。

追问与陷阱：「你还参加过什么竞赛？没拿奖为什么？」——没打过竞赛就承认，然后接编程能力的替代证据（项目代码量、机试练习量），不要现编。

失分点：低分课的归因落在「老师给分低」上；分数问题支支吾吾，显得连自己的成绩单都不熟。

## 收尾题：你有什么想问我们的吗

**问题：你有什么想问我们的吗？**

骨架：问一个只有他们能答的问题——课题组目前的工作节奏、新生第一年怎么进课题、方向上最近在关注什么。准备两个，现场看气氛用哪个。

失分点：问「我能不能被录取」（没人会答真话）；说「没有问题」（热情度直接打折）。
