# CV/NLP/强化学习题库

定下方向再刷这篇：报哪个方向刷哪块，另外两块扫熟骨架即可。三个方向各挑追问率最高的一批题，格式比前两篇紧凑——骨架加主要追问，细节顺着 612、613 的机制补。

## CV 方向

**四大任务的区别。** 骨架：分类——整图一个标签；检测——框加类别；语义分割——逐像素类别，同类实例不区分；实例分割——逐实例像素，每个物体单独一块。失分点：语义和实例分割的区别说不清，这题就是冲这个来的。

**IoU 与 mAP。** 骨架：IoU 是交并比 → mAP：按置信度排序画 PR 曲线求面积，各类别 AP 取平均 → 常用判定阈值 IoU 0.5。追问 COCO 指标为什么高——对多个 IoU 阈值取平均，要求更严。

**NMS。** 骨架：按置信度排序 → 取最高分的框 → 删掉与它 IoU 超阈值的所有框 → 重复直到处理完。为什么需要：同一目标会有一堆重叠框，留一个。

**两阶段与单阶段检测。** 骨架：两阶段（Faster R-CNN 系）先提候选区再分类回归，精度高速度慢；单阶段（YOLO、SSD）一次回归直接出框，快。追问 Anchor——预设的一组参考框，网络在它上面修正；Anchor-free 直接回归边界，省去预设。YOLO 演进主线一句话：backbone 换代加多尺度特征融合，精度和速度的反复平衡。

**FPN 与 ViT。** FPN：自顶向下加横向连接，高层语义强、低层定位准，融合两者。ViT：图像切块当 token 进 Transformer，全局注意力 → 归纳偏置弱（没有局部性先验），小数据不如 CNN，大数据反超。最后一问是 Cv 和 613 的连接题，值得单独背一遍。

## NLP 方向

**词向量。** 骨架：词映射成稠密向量，语义相近则向量相近 → Word2Vec 两种训练：CBOW 用上下文预测中心词，Skip-gram 反过来，后者对低频词更好。追问和 one-hot 的区别：维度低、能算相似度、有语义。

**Transformer 为什么取代 RNN。** 骨架：并行计算、长距离依赖一步直达、易扩展到大模型。追问劣势：序列长度的平方复杂度。多头注意力和位置编码的机制在 613，那里答清楚这里就轻松。

**BERT 与 GPT 的分岔。** 骨架：BERT 是 Encoder-only，预训练任务 MLM（原版还带 NSP），双向上下文，适合理解类任务；GPT 是 Decoder-only，自回归语言模型，单向，适合生成。追问 Encoder 和 Decoder 的分工——前者双向看全文，后者单向逐词生成，Cross-Attention 把两者连起来（翻译、多模态都是这个结构）。

**LoRA。** 骨架：冻结原权重，只训练插入的低秩增量矩阵 → 参数量小一个数量级，部署时能合并回原模型。加分：知道 Flash Attention 治的是显存访问效率，不是精度。

## 强化学习方向

**和监督学习的区别。** 骨架三条：没有标签，只有奖励；奖励延迟反馈；数据由智能体自己交互产生，动作影响后续状态。少说一条就完整不了。

**MDP 与折扣因子。** 骨架：状态、动作、奖励、转移概率、折扣因子 γ → 马尔可夫性：未来只依赖当前状态 → γ 的两个作用：无穷级数收敛、给近期奖励更高权重。

**Q-Learning 与 SARSA。** 骨架：都是值函数迭代 → Q-Learning 更新用下一状态的 max，是 off-policy，学的是最优策略的值；SARSA 用实际执行的下一个动作，是 on-policy，学的是当前策略的值。一句话记忆：max 是乐观的，实际是保守的。

**DQN。** 骨架：神经网络近似 Q 函数 → 两个关键组件：经验回放打破样本相关性，目标网络稳定训练目标。追问过估计——max 操作会高估，Double DQN 把选动作和算值拆开。

**策略梯度与探索。** 骨架：策略梯度直接对策略求导（REINFORCE），Actor-Critic 用 Critic 估值降方差 → 探索与利用：ε-greedy 以小概率随机探索 → 真实应用的难点在奖励设计和稀疏奖励，这句说出来就是应用层的理解。
