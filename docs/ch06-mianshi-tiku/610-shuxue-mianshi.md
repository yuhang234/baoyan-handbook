# 数学面试题

数学在面试里是个筛子：报 AI、CV 这类方向，数学题几乎必到。考法只有两种——直接问概念，或者问连接（泰勒展开和梯度下降、SVD 和 PCA、交叉熵和最大似然）。第一种考你背没背，第二种考你懂没懂，准备时两头都要占。按四门课给骨架。

## 高等数学

**极限是什么？怎么求？** 骨架：极限描述自变量趋近时函数的逼近趋势 → 求法清单：等价无穷小替换、洛必达、泰勒展开、夹逼准则、两个重要极限。追问洛必达什么时候不能用——不是未定式（0/0 或 ∞/∞）就违法，用完极限不存在也不行，这条是常设的陷阱。

**导数、偏导、方向导数、梯度。** 高频递进题，一条链说到底：导数是一元函数的变化率 → 偏导是沿坐标轴方向的变化率 → 方向导数是沿任意方向的变化率 → 梯度是方向导数取最大值的方向，模是最大变化率。追问为什么负梯度方向下降最快——梯度指向函数增长最快的方向，反着走就是最快下降。这题和机器学习直接连通，务必答顺。

**泰勒展开。** 骨架：用多项式在一点附近逼近函数 → 一阶形式 f(x)≈f(x₀)+f′(x₀)(x−x₀) → 梯度下降就是一阶泰勒展开的应用：沿负梯度走一小步，函数值保证下降。追问牛顿法——用二阶信息，收敛快但要算海塞矩阵，这就是差异所在。

**连续、可导、可微的关系。** 骨架：一元——可导必连续，连续不一定可导（|x| 是标准反例）；二元——偏导存在不一定可微，偏导连续才可微。反例记不住这题就答不完整。

**极值与中值定理。** 骨架：驻点不一定是极值点 → 一元看一阶导变号或二阶导符号 → 多元看海塞矩阵正定性 → 鞍点是各方向有增有减的点。拉格朗日中值定理一句话：区间内至少存在一点，切线平行于端点连线。

## 线性代数

**秩。** 骨架：极大线性无关组的向量个数 → 也是非零子式的最高阶数 → 用途：判断方程组解的结构，满秩才有唯一解。

**特征值与特征向量。** 骨架：Av=λv，变换后方向不变的向量 → 求法：特征方程 |A−λE|=0 → 意义：线性变换的主方向。追问相似对角化条件——有 n 个线性无关的特征向量；为什么要对角化——幂运算快，主成分分析靠它。

**SVD 与特征值分解。** 骨架：A=UΣVᵀ → 特征值分解只对方阵，SVD 对任意矩阵都成立 → 应用：PCA、推荐系统、图像压缩。两者的区别是必考追问，答不出应用直接减分。

**正定矩阵与范数。** 正定：xᵀAx>0 对任意非零 x，判定看特征值全正或顺序主子式全正，连接点：海塞矩阵正定保证极小值。范数：L1 是绝对值之和，L2 是欧氏距离 → 机器学习连接：L1 产生稀疏解做特征选择，L2 让权重平滑——为什么 L1 稀疏，因为它的等高线在坐标轴上有尖点，容易在轴上取到最优。

## 概率论

**贝叶斯公式。** 骨架：P(A|B)=P(B|A)P(A)/P(B)，先验、似然、后验三个词要到位 → 经典应用：医疗检测的假阳性悖论——检出率高不等于患病概率高，人群基数差着数量级。

**极大似然估计。** 骨架：找一组参数使观测数据出现概率最大 → 步骤：写似然函数 → 取对数 → 求导置零 → 验证是极大。两个必考连接：高斯噪声假设下和最小二乘等价；分类问题的对数似然就是交叉熵。

**大数定律与中心极限定理。** 骨架：大数定律说样本均值依概率收敛到期望；中心极限定理说独立同分布变量之和近似正态，与原分布无关。一句话分清：一个说均值稳，一个说和的分布。

**期望方差协方差。** 骨架：协方差衡量线性相关的方向，相关系数是标准化协方差 → 独立必不相关，不相关不一定独立——反例要能举一个。这组题看着基础，答不利索的老师会直接怀疑基础课。

**信息熵与交叉熵。** 骨架：熵是不确定性的度量 −Σp·logp → 交叉熵是用预测分布编码真实分布的代价 → KL 散度 = 交叉熵 − 熵。机器学习连接现成：交叉熵损失的出处。

## 离散数学

抽到概率低，准备三个就够：等价关系——自反、对称、传递，例子用同余；欧拉路径——每条边走一次，判定条件是连通图中度为奇数的点是 0 或 2 个；哈密顿路径——每个点走一次，判定是 NP 难的，别和欧拉混。数学归纳法会口头演示：奠基加归纳步骤，例子用 1+2+…+n。

---

数学题的答题原则是「定义先行、意义收尾」：先把背过的定义说准，再用一句它为什么重要、和什么连接收住。只背定义像复读机，只谈意义像空谈家，两头都占才算过。
