# AI/机器学习面试高频题

报 AI 方向，这篇是主线题库。深度学习（613）问的是「为什么」，这篇问的是「是什么、怎么选」——基础概念、经典模型、评价指标、训练技巧、工程实践五层，每层挑最经得起追问的题。

## 基础概念层

**四种学习范式的区别。** 骨架：监督——标签直接给（分类、回归）；无监督——从数据结构找规律（聚类、降维）；半监督——少量有标签加大量无标签；强化——环境奖励延迟反馈。追问各举一个算法和场景，举不出等于没懂。

**过拟合与欠拟合。** 骨架：过拟合——训练好验证差，学了噪声；欠拟合——两者都差，容量不够。解决：过拟合用更多数据、正则化、Dropout、早停、简化模型；欠拟合加特征、加大模型、减正则。追问怎么判断——画训练和验证的 loss 曲线，两条线的形状就是答案。

**偏差与方差。** 骨架：偏差是预测期望与真实的偏离，欠拟合主导；方差是对数据扰动的敏感度，过拟合主导 → 目标是两者的平衡，不是都压到零。

**L1 与 L2 正则化。** 骨架：损失里加权重惩罚 → L1 绝对值之和产生稀疏解，L2 平方项让权重整体变小。为什么 L1 稀疏——它的约束区域有尖点，最优解容易落在坐标轴上。这题跨数学和机器学习两头，见 610。

**交叉验证。** 骨架：k 折——数据分 k 份轮流做验证取平均 → 用途：小数据下的稳健评估与调参。

## 经典模型层

**逻辑回归。** 骨架：线性组合过 sigmoid 输出概率 → 为什么用交叉熵不用 MSE：MSE 加 sigmoid 是非凸的，且梯度带 sigmoid 导数会饱和；交叉熵下梯度形式干净，预测误差直接进梯度。追问名字叫回归为什么是分类——它回归的是概率。

**SVM。** 骨架：找最大间隔超平面 → 支持向量决定边界 → 核技巧映射到高维处理非线性 → 常用核：线性、RBF。追问和逻辑回归的区别——合页损失对交叉熵，输出间隔对概率，一个看几何一个看统计。

**决策树三兄弟。** 骨架：ID3 用信息增益（偏向取值多的特征）→ C4.5 用信息增益率修正 → CART 用基尼系数且支持回归。追问剪枝——预剪枝在建树时停，后剪枝建完再收。

**集成学习。** 骨架：Bagging 并行采样降方差，随机森林是行列双重随机；Boosting 串行纠错降偏差，演进链是 AdaBoost 改权重 → GBDT 拟合残差 → XGBoost 二阶泰勒加正则加工程优化。追问为什么随机森林不易过拟合而 boosting 要控学习率——降方差和降偏差是两回事。

**K-means。** 骨架：随机选 k 个中心 → 按最近分簇 → 重算中心 → 迭代到收敛。追问：是监督还是无监督（无监督，连「监督」指什么一起答）；k 怎么选（肘部法）；对初值敏感（k-means++）；只能划凸形簇。这几个追问是 2025 年某校面试的原题级组合。

**朴素贝叶斯。** 骨架：贝叶斯公式加特征条件独立假设 → 「朴素」指的就是独立性假设，现实里不强但效果好。

## 评价指标层

**精确率、召回率、F1。** 骨架：精确率是查准——预测为正里真对多少；召回率是查全——真为正里找到多少；F1 是调和平均。什么时候偏重谁：癌症筛查重召回，漏诊代价大；垃圾邮件重精确，误杀正常邮件代价大。能按场景选指标，才算真懂。

**AUC。** 骨架：ROC 曲线下面积，阈值无关 → 物理意义：随机取一正一负，正样本得分更高的概率。失分点：只会说「曲线下面积」，说不出物理意义。

**样本不平衡。** 骨架：数据层面——过采样（SMOTE）、欠采样；算法层面——类权重、focal loss；评估层面——弃用 accuracy，改用 F1 和 AUC。三层各说一个才算完整。

## 训练技巧层

**优化器演进。** 骨架：SGD 随机小批量 → Momentum 加惯性 → RMSprop 自适应学习率 → Adam 动量加自适应，默认首选。追问 Adam 收敛快但泛化有时不如调好的 SGD+momentum，为什么——能答出「自适应学习率在平坦极小值附近表现不同」这个量级就够了。

**归一化与标准化。** 骨架：min-max 归一到 [0,1]，z-score 标准化到零均值单位方差 → 为什么要做：量纲统一后梯度下降收敛快 → 树模型不需要，按分裂点切分对单调变换不敏感。

**学习率。** 骨架：太大震荡发散，太小收敛慢 → 衰减策略：阶梯衰减、余弦退火、warmup。

## 工程实践层

**你的模型用了多少数据、训练了多久？** 这是真实面经里的高频题，考的是你有没有真做过。骨架：数据规模 → 划分比例 → 硬件条件 → 收敛轮数与判断标准（验证集不再提升）。数字必须脱口而出，含糊就露馅。

**loss 不下降怎么排查。** 骨架：先查数据和标签（最容易错的地方）→ 再查学习率 → 归一化 → 代码里的梯度 bug 和数据管道 → 最后才怀疑模型结构。把顺序答对，比背十个可能原因值钱。
