# 机试指南

机试是保研考核里少数完全确定的部分：考点固定、判分客观、投入必有回报。而且它的权重常常被低估——不少学校机试不及格一票否决，面试答得再好也救不回来。

## 先分清两种模式

**ACM 模式**：给你题目描述，自己写 main 函数、自己处理输入输出，程序读 stdin、写 stdout。**核心代码模式**（LeetCode 式）：函数签名给定，你只填函数体，输入输出平台管。

目标学校用哪种一定要提前查经验帖。算法会写但输入输出处理不明白，是 ACM 模式下最冤的挂法——不是不会，是没练过。

## 训练路径

按层推进，每层练到不查资料能写再进下一层：

- **第一层：语法与模拟。** 字符串处理、日期计算、进制转换、按格式打印。目标：任何输入输出格式都不慌。这是 ACM 模式的地基。
- **第二层：基础算法。** 手写快排归并、二分查找（边界！）、前缀和与差分、双指针、贪心入门。
- **第三层：数据结构。** 栈（表达式求值是经典题）、队列、链表、二叉树遍历、堆、并查集。
- **第四层：搜索与 DP。** DFS、BFS、回溯，0-1 背包、完全背包、最长上升子序列、最长公共子序列、数字三角形。
- **第五层：图论。** Dijkstra、Floyd、最小生成树、拓扑排序。

时间紧的话砍第五层：绝大多数保研机试落在前四层，图论考到也就是 Dijkstra 模板，考前背一个备着。

两个执行细节：一是语言固定一个就够，机试拼的是速度不是语言广度，C++、Java、Python 都行，Python 省下的打字量在大数和字符串题上是真优势；二是每道题做完必须复盘——错在哪、有没有更短的写法、下次怎么一眼认出这类题，不复盘的刷题量是假的。

## 考点分级

- **必会**：模拟、排序、二分、DFS/BFS、背包、字符串处理。覆盖率九成。
- **高频**：前缀和差分、单调栈、单调队列、并查集、拓扑排序。
- **加分**：线段树、树状数组、字符串哈希。绝大多数学校考不到，别在前期碰。

## ACM 模式的输入输出坑

这些坑挂掉的代码，算法部分往往是对的：

- **多组数据**：`while (scanf(...) != EOF)` 或 `while (cin >> n)`。题目说「多组输入直到文件末尾」却不写循环，第一组过了后面全挂。
- **数字和字符串混读**：cin 读完数字再用 getline，要先吃掉残留的换行符。
- **整行含空格**：用 getline，`cin >>` 遇空格就断。
- **数据量大**：cin 加 `ios::sync_with_stdio(false)`，或者干脆用 scanf。
- **输出格式**：行末空格和换行有的 OJ 严格判；浮点保留位数用 printf 最稳。
- **大数**：C++ 要手写高精度，Java 有 BigInteger，Python 天生支持。语言选型前先想清楚这题考不考。

## 临场策略

先通读全部题目，从最有把握的做起——目标是总分不是完美。OJ 实时反馈，过一题是一题；WA 了先查边界条件和输入格式，再怀疑算法，这个顺序不能反。想不出正解就把暴力写对，部分分是真实存在的。考前把这几个模板白纸默写一遍：快排、二分、BFS、Dijkstra、01 背包。

机试的准备曲线是前陡后平：前两周从零到能做题最痛苦，之后每天两三题，一个月足够覆盖绝大多数学校的机试强度。它是这一章里唯一能靠刷题量直接买分的科目，优先级排在一切技巧之前。
