# 第七章 心态与复盘

前六章讲「怎么做」，这一章讲「怎么想」。这些帖子都从一个真实的复盘里长出来：先跑一轮再迭代、先改环境别先改自己、意志力该用在哪一层、如何识别自己用勤奋逃避思考、思考用什么形状展开、deadline 的改良、理解先于记住、给时间记账。每一篇结尾都有一个当天就能试的小动作。

- [701 先跑一轮，再让下一轮变聪明](701-xian-pao-yi-lun.md) — agent 式迭代 vs 人类规划者：让环境先回一句话
- [702 先改环境，别先改自己](702-xian-gai-huanjing.md) — 意志力应该配置在环境层
- [703 意志力该用在哪一层](703-yilizai-na-yi-ceng.md) — 把意志力花在系统上而不是冲刺上
- [704 你不是不够努力，是不敢停下来想](704-ting-xia-lai-xiang.md) — 用战术勤奋回避战略思考的识别与破解
- [705 思考是有形状的](705-sikao-you-xingzhuang.md) — 图像思考与声音思考的利弊与选用
- [706 Deadline 驱动的弊端与改良](706-deadline-bi-duan.md) — 依赖截止日的六个代价与改良思路
- [707 重看《三傻》：理解先于记住](707-san-shu-xuexi-fa.md) — 面试复习中「先理解后记忆」的方法论
- [708 《奇特的一生》与时间统计](708-qite-de-yisheng.md) — 把一年看成 36 个 10 天的颗粒度管理
