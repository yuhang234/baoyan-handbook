# 第七章 心态与复盘

前六章讲「怎么做」，这一章讲「怎么想」。这些帖子都从一个真实的复盘里长出来：先跑一轮再迭代、先改环境别先改自己、意志力该用在哪一层、如何识别自己用勤奋逃避思考、思考用什么形状展开、deadline 的改良、理解先于记住、给时间记账。下半部分更贴身一些：主体性、学习环境、焦虑与速度感、自律的波动、产品思维、行动与优先级，最后一篇回到这本手册本身——它是怎么被一点点写出来的。每一篇结尾都有一个当天就能试的小动作。
