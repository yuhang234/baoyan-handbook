# 重看《三傻》：理解先于记住

最近重看《三傻大闹宝莱坞》，对里面那句「追求卓越，成功就会在不经意间追上你」有了完全不一样的感受。以前只当是句鸡汤，现在再品，它说的根本不是成功学，是学习方法论。片子里兰彻为什么能一直当第一名？他不是比别人更能背，是他从根子上理解了原理，所以敢当场指出定义错了。

## 我把自己卡在了前十页

这个点戳中我，是因为准备推免复习时我正犯着片子里校长那种错误。对着一本专业教材，从第一页开始逐字逐句看，碰到不懂的地方就卡在那儿，非得把这里完全弄明白才肯翻下一页。结果一周过去，我还在前十页打转。

后来发现不对：**你把「理解」和「记住」的顺序搞反了。** 你以为得先全记住，才能慢慢理解。但实际上，理解是一个过程，不是一个起点。同一个观点我看十遍，每一遍都有新收获：第一遍只知道大概讲了什么，第三遍才明白它真正想表达的问题在哪，到第十遍才能把它和我自己的想法接起来。如果你要求第一遍就完全理解，那你可能永远走不出第一章。

## 硬看、重复看，都不如放一放再看

有段时间读一篇领域内的经典论文，好多推导和新概念看不懂。要是放在以前，我肯定把每个公式抄一遍、逐行推导，卡住就不往下走。那天不知道怎么想的，我跳过去了：先把整篇看完，知道它要解决什么问题、整体思路是什么、哪些部分真不懂。隔了三天再看第二遍，很多之前看不懂的地方突然就顺了——原来它前面的假设我在另一篇文章里已经见过，只是当时没联想到一块儿。像拼图，这一块拼不上，别死摁着它，先拼周围的，拼着拼着就知道这块该放哪了。

所以这三句话我现在当成纪律：**不能一直看，不能一直看重复的，不能一直硬看。**

- 一直看重复的：已经理解的知识点，还每天拿出来翻一遍，美其名曰复习巩固。你都理解了，它就是你的了，有这个时间看点新的不好吗。
- 一直硬看：碰到不懂的死磕到底。磕一天没磕懂，不是你笨，是积累还没到。放一放，知识网铺大一点，那个节点自己就接上了。

那什么叫「理解了」？你能用自己的话把它说出来，你知道它能解决什么问题，知道它和别的方法比好在哪、坏在哪。至于原文怎么措辞、符号顺序怎么写，没必要一字不差。面试的时候，老师要的是你懂，不是你会背。

还有抄笔记这件事。上课哗哗抄，PPT 每个字都抄，抄了满满一本，下课再也没看过——这时间浪费得可惜。上课重点是听懂，不是抄。我现在笔记只记两个东西：不懂的问题，和突然想到的灵感。懂了的东西不记，它已经是我的了。

## 「追求卓越」的新解

以前我理解错了，以为那句话是「好好努力成功自然来」，这不是废话吗。现在才明白它说的是**聚焦过程，忘掉结果**。你越想「能不能拿到推免资格」「老师会不会要我」，越焦虑，越做不好事。反过来，材料就一份份改到最好，知识点就一个个去理解，不懂就查，不会就问。过程做到位了，结果不会差到哪去；天天盯着结果，动作反而变形。我大一下根本没想过推免，就是把每门课学好，一年下来排名就上去了；如果那时候天天问「这门课给分高不高」，反而可能捡了芝麻丢了西瓜。

变通也是同理。我照搬过别人经验贴里「第一遍必须全部看懂」的方案，卡得进度奇慢；后来改成第一遍快速过、不懂做记号、第二遍逐个攻破，又快又透。别人的方法再好，也得改成自己的。

## 一个当天能做的动作

今天别再反复看已经看懂的那几页，也别死磕那一个暂时看不懂的知识点。翻过去，看新的，不懂的做上记号，三天后回头再看一遍。该懂的你总会懂，多看几遍，总会有收获。
