# 保研经验总结怎么写

你现在看到的这个网站，最初只是一个悬了很久的待办事项：写一篇保研经验总结。

这个念头从我拿到拟录取结果那天就有了，但它在我脑子里躺了几个星期，一直停留在标题阶段。不是没时间，是每次一想到它，就感觉面前立着一堵墙：三年要走过的路，信息战、弯路、面试、复盘，怎么也得写几万字吧？要从哪写起？越想越大，越想越不敢动笔。

如果你也有一个类似的庞大复盘任务，这篇写给你。

## 卡住的原因：任务太大，大脑畏难

复盘这件事有个悖论：它最有价值的时候，往往也是你最不想做的时候。因为它要求你把过去摊开来重新看一遍——包括那些不太光彩的弯路。大脑对这种「又大又可能难受」的任务，默认策略就是拖延。

所以破局点不在「挤出更多时间」，而在**把任务改小，小到大脑不再报警。**

## 微积分解法

我后来用的办法，姑且叫「微积分解法」：把一条长跑切成无数小步，每一步小到当天就能完成。具体分两步。

**第一步：今晚十分钟，只列骨架。**

不写正文，不追求完美，就列几个核心的段落标题。比如一篇保研经验帖的骨架可以是：

1. 个人背景（排名、绩点、科研与竞赛经历）
2. 择校与信息战（我踩过的坑）
3. 机试与面试的实战复盘
4. 给学弟学妹的几条忠告

列完就停，去休息。别小看这十分钟——「从零到一」的启动成本是最高的，骨架一旦立起来，后面的每一步都有了抓手。

**第二步：明天挑最容易的一块，写五百字。**

不是最难的那块，是**最容易**的那块。比如吐槽踩过的坑，往往最有话说，先写它。写完就停，明天再选下一块。

这个办法的关键在于承认一个事实：几万字不是一个动作，是几百个动作。你每天要做的从来不是「写完总结」，只是「今天这五百字」。五百字没有人写不出来，几万字很少有人写得出来——差别只在切没切。

## 这本书就是这么长出来的

你手上这本书，就是用这个办法一点点长出来的。

它不是某天灵光一现写完的，而是先立目录，再一章一章往下推进；每一章又拆成一篇一篇的帖子，每篇只回答一个小问题。哪天状态好，多写半篇；哪天卡住，就先写当时最容易的那一篇。回头看，每个「今天」做的事都小得可笑，但叠了足够多个「今天」，一本书就站在这里了。

庞大的复盘任务几乎都可以这么长：一份保研总结、一套复习笔记、一个项目的文档。**别等想清楚全貌才开始，全貌是写着写着才浮现的。**

另外说一个附赠的收获：写总结的过程，本身就是重新认识自己实力的过程。写到「踩过的坑」，你会发现很多坑有通用解法；写到「怎么走出来的」，你会发现自己比印象中能干得多。这份对自身能力的校准，比总结本身还值钱——面试里被问到项目细节时那种笃定，就是从这里来的。

## 一个当天能做的动作

今晚睡前十分钟，给你那个拖了很久的复盘任务列出四段骨架，写完就休息。明天，挑其中最容易的一段，写五百字。
