# 搞清楚事情的优先级

先说一个我自己的名场面。有一次我下决心写保研经验总结，刚打开文档敲了个标题，突然想到一个八竿子打不着的问题，随手搜了半小时；搜完又顺着另一个好奇的点跳走了。一个下午过去，总结还是只有标题，我倒是知道了几个跟保研毫无关系的冷知识。

这种事在我身上反复发生：明明定了要做 A，身体却诚实地去做 B、C、D。后来我认真复盘了一次，把它的机制、对策都想清楚了。

## 分心的本质是畏难

第一个发现：**分心不是好奇心的错，是畏难情绪的马甲。**

「写保研经验总结」对大脑来说是个大任务：要深度回顾三年，要面对自己的挫败和弯路，费脑又可能难受。潜意识一算不划算，就立刻抛出一些「容易获得即时反馈」的伪需求——搜个冷知识、比个工具、整理个文件夹。查八卦当然比写总结轻松多了，于是每次都赢。

所以跟分心对抗，靠意志力堵是堵不住的，得看懂它在替你逃避什么。逃避的东西越具体，对策越好下。

## 三个机制

复盘之后我搭了三套机制，一直用到现在。

### 1. 帕累托防护墙

把接下来三到六个月里，对自己影响最大的一件事找出来——是一段排名，一篇论文，还是一场比赛。把这一件事定为**主线任务**，写下来，贴在看得见的地方。

墙内只有主线。墙外的一切——新工具、新方向、有趣的新名词——统统算支线或娱乐，只许安排在精力最差的时段。每天精力最好的黄金时段，雷打不动只给主线。20% 的核心投入决定 80% 的结果，这就是把「帕累托法则」当成一堵墙，替主线挡住所有七七八八。

### 2. 闪念回收站

好奇心不压杀，引流。手边放一个随手可记的地方（我用的就是普通的笔记软件，建了一页叫「闪念回收站」）。做着主线，脑子里蹦出「那个工具好不好用」「那个概念是什么意思」，**一秒之内记进去，立刻把视线拉回屏幕。** 跟自己说：记下了，晚上统一处理。

这一招的妙处是给杂念一个出口，大脑就不用反复提醒你了——它知道你记下了，不会丢。多数闪念到了晚上再看，一半已经不值得搜了。

### 3. MVP 思维终结工具内耗

我还有个毛病叫「工具仓鼠症」：反复比较哪个软件最好用、哪个平台排名最高，好像选到完美工具，事情就会自动做好。实际上工具的尽头是业务本身，比较十篇文章得到的二手经验，不如自己跑通一个最小案例。

给自己设个微型目标：**一小时内，用最简配置把它跑通一个 Hello World。** 跑通了，你对它的理解超过读十篇评测；不好用，立刻弃坑，绝不留恋。

## 一条检验标准

怎么判断自己是「在规划」还是「在逃避」？我用的标准是看**接下来的动作有没有产出单位**。查资料、比较、列大纲，本身都不是产出；写完的一段、跑通的一版、发出去的一封，才是。动作说不出口产出是什么，多半就是在原地打转。

优先级想不清楚的时候，别急着排清单，先回答一个问题：**这个阶段的主线是哪一件事？** 主线立住了，清单自动塌缩成一列。

## 一个当天能做的动作

拿一张纸，写下你未来三个月的主线任务（一句话，只能写一件），然后设一个二十五分钟的番茄钟，把今天剩下的黄金时间全给它。其余想法，全部记进回收站，晚上九点再见。
