# 简历制作：从模板到自我营销

保研简历和求职简历的读者不一样：读它的是高校老师和面试官，不是 HR。很多院校通知里没要求交简历，有人就不做了，这是误判——简历有两个固定使用场景：**面试时递给评审老师**（老师照着它提问），**邮件联系导师时作为附件**（导师靠它决定要不要回你）。这份纸实际上是你的面试提纲和自我营销页，值得认真做。

## 模板怎么选：我试过二十多个

市面上的保研简历模板非常多，我把手头能找到的都打开过一遍，最后沉淀下来的选用逻辑是：

- **单页，无条件的单页。** 本科生所有经历压缩在一页里绰绰有余，两页说明你不会取舍。
- **颜色最多两种。** 一个主色加一个强调色足够，见过把六种高饱和色塞进一页的模板，信息没记住，配色先记住了。
- **字体克制。** 中文宋体或微软雅黑，英文和数字用 Times New Roman，全文统一。
- **结构大于样式。** 好模板的共同点不是好看，是板块清楚：教育背景、科研经历、竞赛荣誉、个人技能，位置固定、层级分明。花哨的排版只会分散注意力。

工具上不用纠结。Word 模板改起来快，LaTeX 模板排版精致但要学编译，都有现成的，选顺手的。我最后用 Word，原因很实际：反复改内容时改得快。

## 内容组织：老师看什么

**教育背景**放最上面。学校、专业、时间段之后，紧跟三个数字：排名（写成相对形式，如 7/330，前 2%）、绩点、英语水平。下面列四五门高分核心课——课程列表其实是在告诉老师你的知识结构长什么样，挑和申请方向相关的。本科学校如果不是顶尖知名院校，可以按实际层次注明（985/211/双一流），这不是虚荣，是帮外校老师快速定位。

**科研经历**是核心板块，占最大篇幅。写法后面几篇细讲，这里只说一条原则：每段经历按「研究问题 → 我负责什么 → 量化结果」三行展开，让老师三秒钟看清一件事——你在其中是主角还是观众。

**竞赛与荣誉**用列表，一行一项：奖项全称、等级、时间。重要的放前面，奖学金和竞赛分栏排更清楚。

**个人技能**别堆名词，用「掌握 / 熟悉 / 了解」三个层级如实分层。面试官看到「精通」两个字是会出题的。

## 一个容易被忽略的细节：简历即议程

面试老师拿到你的简历，大概率照着它提问。所以简历上每一行都要经得起被问：写了某门课的高分，就要能复述那门课的核心内容；写了某个项目，就要能讲清技术细节（怎么讲，见第二章那篇项目深挖）。

反过来用这个机制：**把想让老师问的东西写显眼，不想被问的别写。** 我的简历把一作论文放在科研经历第一条、写得最满，面试里大部分时间果然都在聊它——这正是我要的，因为这块我准备得最充分。

## 版本管理

和陈述一样，简历也要存版本。我从初版到最后改了将近十版，每一版动的地方不同：先调内容结构，再调措辞量化，最后微调排版。两个提醒：

- 每次改完导出 PDF 存档，文件名带日期。面试前一天还在改简历是常态，你要能找回昨天那版。
- 所有版本改完后统一核对一遍数字：排名、绩点、各项数据要和成绩单、陈述、报名表完全一致。我吃过口径不一致的亏，好在是在投递前发现的。
