# 推荐信：找谁写、怎么写、何时要

推荐信大概是保研材料里最「玄」的一份：内容不是你写的，权重却不小。我前后办过几封，最大的体会是一句朴素到近乎残酷的话——**推荐老师是谁，比推荐信写了什么更重要。** 这句不是我发明的，是一份推荐信模板的使用说明里写的，办完一轮之后我完全认同。

## 找谁：两封的分工

多数院校要求两封，推荐人要求教授或副教授。两封信最好分工明确，覆盖你的不同侧面：

- **一封来自懂你科研的人。** 科研指导老师、项目负责人，能写你在研究里的具体表现：问题意识、执行力、论文写作。这封信的价值在细节的真实感——只有真正带过你的人才知道的那些细节。
- **一封来自了解你学业的老师。** 专业课授课教师、班主任或专业负责人，能从课堂表现、成绩走势、学习态度的角度背书。职称高的推荐人有他的分量，这一点不必回避。

理想情况是两封都满足「职称够 + 真的了解你」。如果不可兼得，优先保证至少一封有真实相处细节——全是形容词堆出来的推荐信，读的人一眼就能识别。

## 怎么写：替老师准备好草稿

现实是：老师很忙，多数推荐信是你起草、老师修改签发。这不是潜规则，是双方都省事的正常流程。我的做法：

1. **先问意愿，再给草稿。** 当面或消息里说明来意（申请哪些院校、什么方向、截止时间），老师同意后，再把草稿和支撑材料一起给过去。
2. **草稿按固定结构写。** 身份与关系（我是谁、以什么身份了解这位学生）→ 学业表现（排名、课程、学习能力）→ 科研表现（做过什么研究、体现出的能力）→ 个人品质 → 综合结论（明确说「郑重推荐」）。每段给一到两个具体事实支撑，比如「以第一作者完成某项研究，论文目前在投」，比「科研能力突出」有用得多。
3. **给老师留修改空间。** 草稿里用我自己的口吻写事实，评价性的话留给老师定——每个老师有自己夸学生的方式，改过的信才像他的话。
4. **两封信要错开角度。** 如果两封内容几乎一样，等于浪费了一个名额的信号通道。

## 何时要：越早越好，按截止时间倒排

推荐信的时间风险被严重低估。它要经过「老师同意 → 起草 → 老师修改 → 签字或电子签名 → 盖章（部分院校要求）→ 扫描归档」好几道工序，任何一环卡在老师出差、放假，你就抓瞎。我的教训是第一次参营时推荐信和盖章材料都准备晚了，赶得非常狼狈。

倒排方法：从最早一批夏令营的截止日期往回推，给老师的时间至少留一到两周，盖章流程再单独留几天。大三下学期一开学就可以去开口——问得早不冒昧，问得晚才失礼。

## 最后两个细节

- **电子签名存档备用。** 在白纸上签好自己的名字，扫描抠图存成透明底图片，很多材料末尾要用。有些老师也愿意用电子签章出 PDF 版推荐信，问清对方院校收什么格式。
- **礼貌闭环。** 每一批申请结束后，给老师报一声结果，道谢。你会用到套磁、复试、毕业各种场合，师生之间的信用是长线资产。
