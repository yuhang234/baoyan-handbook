# 中英文自我介绍

自我介绍是每场面试的开场白，也是你唯一一段百分之百确定会发生的对话。它值得被当成一件作品来打磨：中英文各一版，1 分钟和 3 分钟各一套，共四份稿子。这篇讲这四份稿子怎么写、怎么记。

## 结构：三分钟能装下什么

3 分钟版本我按四段走：

1. **开场**（10 秒）：姓名、学校、专业、一句定位。定位要具体：「主要关注计算机视觉与多模态方向，目前有一篇一作论文在投」，比「我对人工智能充满热情」信息量大十倍。
2. **学业**（30 秒）：排名 7/330、绩点、两三门和方向相关的高分课。数字放这里，因为这是全文最不怕被打断的部分。
3. **科研与竞赛**（90 秒）：一段一作研究讲透（问题、方法、指标、论文状态），其他经历一句话带过。这是主菜，时间砸在这里。
4. **规划收尾**（30 秒）：为什么选这里、研究生阶段想做什么。落到具体的方向词上，别落在「努力学习回报老师」上。

1 分钟版本不是把 3 分钟念快一倍，是砍掉第 4 段的展开、把科研压缩成两句话：一段定位 + 关键数字 + 一句研究描述。保留的信息优先级：排名和论文 > 方法细节 > 其余一切。

## 记忆点：给老师一个抓手

面试老师听完几十分自我介绍，能记住的只有带钩子的那几个。钩子通常是数字：排名 7/330（前 2%）、模型 mAP@0.5 0.865、一篇 HSSC 一作在稿加一篇 SCI 三作发表。这些数字在四份稿子里反复出现，本身就是记忆点。

另一个抓手是概念对：「视觉行为识别 + 教育学理论」这种交叉组合比单一方向好记。你身上如果有类似的结构（两个领域的交叉、一条清晰的成长线），把它放进开场定位里。

## 英文版不是翻译版

两个语言版本的关系是改写不是互译：

- **英文更短。** 同样 3 分钟，英文的语速承载量比中文低，句子要砍掉三分之一，从句全部改短句。
- **英文更口语。** 中文稿可以书面，英文稿要能顺口说出来。写完自己读三遍，凡是舌头打结的句子都改成简单句。
- **结构对齐但措辞不同。** 两版按同样的四段走，方便现场切换，但每句不必逐字对应——背两套独立的稿子，比背一套稿子和它的翻译更不容易卡壳。

英文的常见坑是背诵腔：语调平、过快、眼神飘。对策只有一个——练习时强制自己看镜头或看对面的人说，背熟到「想内容而不是想词」的程度。

## 怎么记：记骨架不记字句

我是这么准备的：先把 3 分钟中文稿逐字写出来打磨两轮，然后**把它压成一张卡片**——每段一行关键词，比如「开场：CV+多模态，一作在投 / 学业：7/330，99 视觉 / 科研：YOLO11m，六类行为，0.865，HSSC / 规划：多模态融合」。之后所有练习都对着卡片讲，不逐字背。这样做的好处是现场状态波动时你只会讲得朴素一点，不会断片；而且每场面试说出来的话术自然、有呼吸感。

AI 可以当陪练：把自己的材料喂给它，让它按你的情况生成几版不同侧重的稿子（偏科研版、偏工程版、偏规划版），你再挑着改。它给的不是最终稿，是让你快速看到同一个事实的不同讲法——这个视角切换自己闷头写很慢。

最后一遍检查清单：数字和简历一致、没有第三方可识别信息、英文稿舌头不打结、1 分钟版独立成立。四份稿子备齐，面试开场这一关就不再是变量。
