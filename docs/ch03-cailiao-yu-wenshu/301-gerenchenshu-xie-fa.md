# 个人陈述怎么写

个人陈述是所有文书里最像「作文」的一份，但它不是抒情的作文，而是一份说服材料：用一到两页纸，让初筛老师相信你有能力、有准备、和这个院系匹配。我的个人陈述前后改了六个版本，这篇把结构和迭代思路都摊开讲。

## 先想清楚谁在读

夏令营和预推免的初筛老师，平均花在一份材料上的时间可能只有一两分钟。这意味着两件事：

- **开头必须直接给结论。** 你是谁、排名多少、有什么拿得出手的成果，第一段就交代，不要铺垫「从小我就对计算机充满兴趣」这种话，老师的耐心比你想的少。
- **结构必须一眼可见。** 用小标题或分段编号把「专业基础 / 科研经历 / 竞赛实践 / 未来规划」切开，让老师可以跳读。

## 我用的四段结构

**一、专业基础。** 一段解决：GPA 和排名（我的写法是 4.31/5.0、专业排名 7/330，位列前 2%）、两三门高分核心课、工具能力（Python、PyTorch、LaTeX 这类真的会用到的）。课程分数挑和申请方向相关的写，比如报视觉方向就突出计算机视觉基础（99 分）。

**二、科研经历。** 这是重头，占全文三分之一以上。每段研究按「研究问题 → 我做了什么 → 结果如何 → 我的收获」展开。比如我的一作研究：针对课堂认知参与难以量化的问题，基于 YOLO11m 做六类课堂行为检测，mAP@0.5 达到 0.865，论文目前在 HSSC 期刊在稿。注意「在稿」要如实写，不要写成「已发表」——这是诚信问题，后面面试也会被追问。

**三、竞赛与实践。** 简写，一两项有分量的就够，别把清单搬进来。简历是干这个的，陈述里竞赛只是补充信号。

**四、未来规划。** 别写「研一打基础、研二发论文、研三毕业」这种万金油，要和申请的院系、方向挂钩：你对哪个方向感兴趣、为什么是这个学院、打算怎么补自己的短板。这段是所有版本里最需要「一校一版」的地方。

## 六个版本是怎么迭代出来的

我的版本演进大概是这条路，供你对照：

- **第一版是长反思稿**，写给自己的，两三千字，把大学三年的认识都倒出来。它不能直接用，但提供了全部素材。
- **第二版压缩成结构稿**，四段结构定下来，删掉所有「我认识到……我体会到……」这类只有自己感动的句子。
- **第三版做了减法**，出了一份只谈排名不报绩点的版本，思路见下一篇。
- **第四版围绕论文润色**，把科研段从「参与了很多」改成「独立负责了什么、数据是什么」。
- **第五版开始分方向**，给不同研究方向的院系换研究兴趣段和规划段。
- **第六版收尾**，逐句删形容词，只留动词和名词。

回头看，前两版解决「有什么」，后面几版解决「对方要什么」。方向不要反。

## 三个实操建议

1. **先建素材库再动笔。** 把排名、课程分数、每段科研的职责和数据、竞赛奖项列成一张表，写作时从表里取数，比边写边回忆快得多，也不容易写错。
2. **每一段都问一句「所以呢」。** 「我参与了数据标注、模型训练和论文写作」——所以呢？改成「我独立完成了数据标注与模型训练，模型 mAP@0.5 达到 0.865」，数字和职责落到自己头上，这句才算写完。
3. **一校一版，但只改该改的。** 规划段和研究兴趣段按院系重写，专业基础和科研段保持稳定。所有版本之间核对一遍数字，别出现这份写 7/330、那份写别的口径的低级错误。
