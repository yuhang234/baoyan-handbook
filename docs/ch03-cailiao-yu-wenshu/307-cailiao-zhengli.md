# 申请材料整理

报名季最狼狈的场景不是面试答不上来，而是截止前一晚发现某个盖章的扫描件找不到、某个 PDF 超过系统限制传不上去。这篇讲申请材料的整理方法：清单、封面目录、合并与签名。它不难，但值得做成一套固定流程。

## 先建总清单

把我实际用过的材料清单列出来，报名前对着它查库存：

1. 报名表（各校系统里填，注意每校口径）
2. 本科成绩单（教务处开具，盖鲜章后扫描）
3. 专业排名证明（学院开，注明「第 X 名 / 共 X 人」）
4. 个人陈述（一校一版，见前面几篇）
5. 个人简历（PDF 版）
6. 身份证正反面、学生证扫描件
7. 英语水平证明（四六级证书）
8. 推荐信两封（签字版扫描）
9. 学术成果材料（论文录用或在稿证明、全文）
10. 获奖证书（按级别排序：国家级 → 省级 → 校级 → 奖学金 → 荣誉）
11. 其他（大创结题证明、社会实践证明等）

每项材料统一扫描成 PDF、统一命名（比如「07-推荐信1-某某大学.pdf」这种编号加内容的名字），放进一个按上述顺序编号的文件夹。命名里带编号的好处是合并时顺序天然正确。

## 封面、目录、合并：一份打包 PDF

很多夏令营要求把材料合并成**一个 PDF** 上传，系统里不可能让你传十几个文件。我的做法：

- **做一页封面**：目标院校院系名、「夏令营申请材料」、姓名、学校、学院、年级、专业、申请专业。一页纸，居中排版即可。
- **做一页目录**：按上面清单的顺序列编号目录，让翻材料的人一眼知道后面有什么。
- **合并**：封面 + 目录 + 各项材料，按编号顺序合成一个 PDF。合并工具很多，注意检查两件事：单文件别超过报名系统的大小限制（超了就压缩图片）；合并后目录页码和实际对得上。

这套「封面 + 目录 + 编号合并」的最大好处，是初筛老师翻你的材料像翻一本装订好的册子。材料散乱和材料整齐，传递的第一印象在内容被读到之前就形成了。

## 电子签名：一次准备，到处能用

很多材料末尾需要签名：个人陈述落款、承诺书、推荐信相关页。白纸黑字签一次名，手机拍清楚，抠图存成透明底 PNG，之后所有要签名的 PDF 都能直接贴。注意签名图片别变形、别压缩得发虚——它是你所有材料里唯一「手写」的部分，糊了很扎眼。

## 维护节奏

- **一校一文件夹。** 每报一个院校，复制一份模板文件夹出来改：封面换校名、陈述换版本、按对方要求增删材料。总清单始终是你唯一的事实来源。
- **一表管截止时间。** 文件夹之外建一张报名追踪表，列院校、系统网址、截止时间、材料状态。做法第一章那篇报名管理讲过，这里只提醒一句：材料状态那栏要精确到「已合并、已上传、已确认」三级，而不是笼统的「完成」。
- **改完任何一份材料，重新合并。** 报名季材料会反复微调，最怕的是改了简历忘了重新合并，传上去的还是旧版。把「重新合并并打开抽查」当成流程的最后一步固定下来。
