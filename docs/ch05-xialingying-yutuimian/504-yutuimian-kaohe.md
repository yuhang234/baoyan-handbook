# 预推免流程与考核特点

夏令营没拿到满意offer，9 月的预推免就是主战场。我参加和围观了几个院系的预推免考核之后发现，形式高度相似、权重差异很大，真题风格几乎可以预测。这篇把流程、形式和题目风格讲清楚。

## 流程与时间线

预推免在 9 月集中进行，节奏比夏令营快得多：

1. **8 月底–9 月初**：各校陆续发布预推免报名通知，多在学院官网和研招网。材料基本沿用夏令营那套（见 501），重新拼装即可。
2. **报名–审核**：几天到一周出初审名单。有的学校还有「预报名系统」，和正式推免系统并行，两遍都要填。
3. **考核**：9 月中旬扎堆，常常两三场挤在同一个星期。
4. **出结果**：考核后两三天到一周。9 月 28 日前后所有待录取走全国推免系统确认，在那之前手里的所有口头和邮件 offer 都要换成系统里的志愿。

一个容易忽略的点：**夏令营和预推免的录取逻辑可能不同。** 我遇到过某个学院，夏令营是老师个人给 offer，预推免改成招生组统一考核、入学后再双选导师——同一个学院，两套规则，直接影响你该花力气在套磁上还是刷考核上。报名前先把「谁说了算」搞清楚。

## 考核形式：无笔试 + 单面为主

理工科的预推免绝大多数是「无笔试 + 单面」，20–30 分钟一个人，面试占比 100%。常见的环节拼装：

- **自我介绍**：3 分钟左右，中英文都有可能。有的明确要求英文，1 分钟，背熟但别背出机械感。
- **英文环节**：两极分化。轻的问生活类——介绍你的爱好、介绍你的家乡；重的给一段英文材料现场阅读加翻译，2 分钟左右。前者考的是胆量，后者考的是词汇，准备策略完全不同。
- **抽题作答**：抽一道专业题，思考 2 分钟后作答。题面基础（见下面真题风格），考临场组织。
- **PPT 汇报**：有的院系要求 5 分钟 PPT，讲博士动机、目标和计划——注意，是**博士**层面的规划，报直博的必须把这个准备到位，拿硕士话术去讲会露怯。
- **自由问答**：剩余 15–20 分钟给提问，聚焦专业课和简历，氛围一般比夏令营正式。

## 真题风格：基础 + 追问链

把我见过的预推免题放在一起，就三个风格：

1. **基础概念，但要答到底层。** 例：「K-means 是有监督还是无监督？『监督』是什么意思？」「为什么用神经网络而不用多元线性回归？」「C 语言里指针和引用有什么区别？」——每道题的第一问都很简单，但一定会追「为什么」，追到你知识的边界为止。
2. **链条式追问。** 数学方向的面试最典型：「叙述某定理的定义 → 换个条件还成立吗 → 不成立的话补什么条件 → 证明一下。」五连追问，每一环都不难，断一环就断到底。应对方式和 502 讲的「目的先行」一脉相承：每答一步，主动交代「这一步的适用前提」，不给追问留钩子。
3. **智力题和开放题。** 偶尔出现「没有刻度的天平、80 个球、只有一个重量不同，最少称几次」这类题，考的不是答案而是分解问题的过程。开放题如「工业大数据有什么特点」，考的是把课程知识和应用场景连起来的能力。

不同院系风格权重不同：数学类几乎全靠追问链，工科信息类更看项目和 PPT，有的学院面试氛围轻松、明摆着在筛背景匹配度。**考核前找到参加过该学院考核的人问一句「什么风格」，比多刷三套题有用。**

## 和夏令营考核的三个区别

- **节奏更快**：从报名到出结果可能只有两周，材料必须复用现成的，别推倒重来。
- **对手更杂**：夏令营刷掉的和临时冲刺的一起进场，你的排位（比如我的 7/330、前 2%）在这个阶段初筛基本不卡人，考核表现说了算。
- **名额更实**：夏令营的优秀营员有鸽掉的，预推免出的名额就是当年真实缺口的反映。这也是 507 讲的捡漏机会出现的地方。

预推免考核本身不深，深的是追问。把每门核心课的基本概念过到「能解释为什么」的层次，再把 PPT 和英文两件套备好，9 月就不是赌运气。
