# "捡漏"与候补策略

保研季有个不太被经验帖提起的词汇：捡漏。指报那些竞争热度明显低于同档次的项目，用普通背景拿到超档 offer。我旁观过几个成功的捡漏案例，也见过把捡漏理解成「随便报报」结果翻车的。这篇讲捡漏项目的特征、信息和风险。

## 捡漏项目的四个特征

低竞争不等于低水平，捡漏项目通常长这样：

1. **新开的项目或方向。** 某校软件工程专业评了 A+，但直博项目推免季才第一次开——知道的人少、没有往年分数线可参考，报名人数远低于它的实际实力。新开的直博、新设的交叉学院，都是这类。
2. **非热门学院承载的热方向。** 同一所学校，计算机学院的人工智能方向挤破头，而信息与工程学部下面的某个院系开同方向的直博，报名者寥寥。方向相同，学院的「牌子」不同，热度差一个量级。
3. **地理位置或校区因素。** 新建校区、离家远、城市不热门，都会劝退一批人。如果你对城市不敏感，这部分折价就是你的机会。
4. **跨学科或基础学科的应用方向。** 数学、物理等基础学部下面的应用类方向，门槛写着「数学强校前列」，听起来吓人，实际报的人少——**高门槛写在纸面上，竞争强度写在报名表里，两件事。**

## 捡漏信息的三个来源

- **官方渠道的「空档信号」**：夏令营名单公示后对照入营人数和优营人数，比例异常宽松的学院值得记下来；预推免阶段直接看有没有「第二批」「补充报名」公告。
- **考核形式本身**：我见过一个学院的预推免，30 分钟面试占比 100%，无笔试，流程清楚得近乎透明——这种「把考核规则写明白」的项目往往也更愿意给认真准备的人机会。
- **招生机制的差异**：有的学院夏令营由导师个人给 offer，预推免改招生组统一考核；有的入学才双选导师。机制差异大的地方，就是信息差大的地方，信息差就是捡漏空间。

## 风险：捡漏不是捡便宜

把丑话说在前面：

- **考核标准不会因为你「捡」而降低。** 那个数学直博项目，面试 30 分钟全程随机追问：定理叙述、反例构造、黑板证明，一样都不能少。门槛高的项目报的人少，但能进来的人也少——捡漏拼的是「别人不敢报」的信息差，不是「我水平不够也能进」的侥幸。
- **直博要按博士价格买单。** 不少捡漏项目是直博，一旦上车没有回头路。冲之前先确认自己要读博，别为了「有学上」签下五年。
- **信息少是双刃剑。** 没有往年数据意味着你也不知道坑有多深：导师情况、毕业去向、组内氛围都要额外花功夫核实（方法见 505），别只看院系牌子就交志愿。
- **候补的机会成本。** 等候补期间，你可能错过其他学校的确认截止时间。候补前列一张时间冲突表：如果候补转正的通知晚于某场确认 deadline，想清楚放弃哪个。

## 操作清单

1. 夏令营公示期：记录各学院入营/优营比例，标出宽松异常的项目；
2. 8 月：对候选捡漏项目做背景核查——学院实力、导师名单、直博/学硕结构、校区位置；
3. 预推免报名期：捡漏项目正常报，不占用主力志愿的时间预算（标 C 场，见 506）；
4. 出结果期：候补转正逐个确认，对照手上的 offer 和确认截止时间做取舍。

捡漏的正确的打开方式是：主力志愿照常打，捡漏作为低成本期权挂在清单上。它是策略的一部分，不是退路，更不是捷径。
