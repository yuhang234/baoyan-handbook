# 控制工程复试专业问题

一场控制工程复试的专业素质测试 80 分，三门课各 5 题：电路原理、微机原理、计算机控制系统。这篇按「问题 → 答题骨架 → 常见失分点」整理，给结构不给全文。

## 电路原理

**1. 基尔霍夫定律的物理意义。** 骨架：集总参数电路的基本定律 → KCL 节点电流代数和为零，本质电荷守恒；KVL 回路电压代数和为零，本质能量守恒 → 列方程前先设参考方向。失分点：只背「和为零」不说守恒本质；漏前提和参考方向。

**2. 戴维南定理与诺顿定理。** 骨架：线性含源二端网络对外等效为电压源串电阻（开路电压 + 除源内阻）；诺顿等效为电流源并电阻（短路电流）；二者可互换，Uoc = Isc × Req；条件是内部线性。失分点：丢掉「线性含源二端」；含受控源求内阻要用外加电源法，不能直接串并联；漏互换关系。

**3. 正弦稳态的相量分析法。** 骨架：把正弦量变复数，时域微积分变成频域代数 → 相量含有效值和初相 → 电感超前、电容滞后 → 四步：表示、画模型、解、反变换。失分点：超前滞后说反；漏 KCL/KVL 的相量形式；只会定义说不出步骤。

**4. 一阶电路三要素法。** 骨架：f(t) = f(∞) + [f(0+) − f(∞)]e^(−t/τ) → 初始值用换路定则画 0+ 电路求 → 稳态值让电容开路、电感短路后按直流电路求 → τ = RC 或 L/R。失分点：换路定则只对电容电压和电感电流成立；τ 里的 R 取错；说不出「3τ–5τ 暂态结束」。

**5. 功率因数及其提高。** 骨架：λ = P/S → 为什么提高：容量一定时有功更大、电流小则损耗小 → 感性负载并联电容补偿最常用，避免轻载。失分点：说不出供电侧为什么在意；「容性无功抵消感性无功」讲不清；不知道过补偿也有害。

## 微机原理

**6. 8086 CPU 内部结构。** 骨架：BIU 管取指、存取数据、形成 20 位物理地址（段左移 4 位加偏移）；EU 管译码执行和偏移地址计算；二者并行，取指与执行重叠。失分点：分工说混；物理地址公式说不出；漏「并行提高效率」。

**7. 中断系统与中断类型。** 骨架：先给定义 → 外部（可屏蔽 INTR / 不可屏蔽 NMI）与内部（除零、单步、断点、溢出、INT n）→ 响应按序：请求、响应、取类型号、保护现场、查向量表、IRET 返回。失分点：INTR 受 IF 控制 NMI 不受，说不出基本没戏；向量表按类型号 ×4 取向量；过程背跳步。

**8. 存储器片选方式。** 骨架：高位地址译码选芯片 → 线选法（电路最简但地址重叠）、全译码（地址唯一，最常用）、部分译码（折中）。失分点：三种优缺点对不上号——这就是题眼；说不出「简单性与地址利用率的权衡」的考查意图。

**9. 8255A 工作方式。** 骨架：可编程并行接口，A/B/C 三个 8 位口 → 方式 0 基本输入输出、无应答；方式 1 选通，C 口出应答线；方式 2 双向，仅 A 口。失分点：方式 2 只有 A 口，高频追问点；C 口应答联络线说不清；不给应用场景。

**10. DMA 原理及与中断的比较。** 骨架：不经 CPU 由 DMA 控制器直传，期间 CPU 让出总线 → 流程：初始化、请求响应（DREQ → HOLD → HLDA）、字节数清零发 EOP 结束 → 优势：硬件直传快、CPU 只在头尾参与、适合成批数据。失分点：流程说不出；漏「CPU 效率」；不给适用场景。

## 计算机控制系统

**11. 系统典型组成结构。** 骨架：按信号流：被控对象 → 传感器 → A/D → 控制器 → D/A → 执行机构，闭环回来 → 三步循环：采集、决策、控制 → 特点：模数混合、离散采样、控制规律由软件实现。失分点：A/D 在反馈通道上别画反；漏「改算法只需改程序」这条存在理由。

**12. 采样定理与采样周期选择。** 骨架：fs ≥ 2fmax，否则频谱混叠无法恢复 → 工程取 5–10 倍留裕量 → 周期权衡四角度：信号复现、控制品质、抗干扰、执行机构响应 → 经验值（温度 10–30s，运动 1–10ms）。失分点：不说混叠机理；没有「不是越小越好」的判断；给不出量级。

**13. 数字 PID 位置式与增量式。** 骨架：位置式输出全值，积分累加，需防积分饱和；增量式输出增量，只用最近三次偏差，天然无扰动切换 → 无积分特性的执行机构用位置式（调节阀），有的用增量式（步进电机）→ 工程上增量式更常用。失分点：公式写混；优点链（误动作影响小、切换无扰动）不完整；场合乱配。

**14. Z 变换及其作用。** 骨架：离散序列的变换，源于拉氏变换代换 z = e^(sT) → 性质：线性、滞后位移、终值定理（要求稳定）→ 作用：差分方程变代数方程、稳定性判据（极点在单位圆内）、控制器设计都在 z 域做 → s 左半平面对应 z 单位圆内。失分点：终值定理不提条件；几何对应说不出；讲不出在控制里用来干什么。

**15. A/D 与 D/A 转换器。** 骨架：A/D 是模拟信号进计算机的输入口，采样、保持、量化、编码四步；D/A 是数字量出给执行机构的输出口 → 指标抓三条：分辨率（位数）、精度、转换时间 → 不是位数越高越好，按精度速度成本综合选。失分点：四步流程说不全；分辨率和精度混为一谈——一个管分辨能力，一个管误差。

## 突击复习的顺序

时间紧就按分值密度排：计算机控制系统 5 题考的是「离散化之后世界怎么运转」，优先吃透；微机原理的中断、DMA、片选是三大必考结构；电路的定理题相对套路，把适用条件过一遍就能防住大部分追问。每题练到 90 秒能口述骨架，就够了。
