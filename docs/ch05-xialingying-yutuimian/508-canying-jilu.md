# 参营记录模板

参了两三个营之后你会发现自己开始记混：哪所学校要的是两份推荐书、哪场面试被问了采样定理、哪个老师的方向和你的项目刚好接得上。记忆在多线程申请季里不可靠，可靠的是记录。这篇给出我用的两份模板：报名期的 ddl 表（501 提过）和营期/面试的现场记录卡。

## 模板一：ddl 总表（报名期用）

一张表从报名管到出结果，五行字段是骨架：

| 学校/学院 | 截止时间 | 是否报名 | 是否入营 | 是否参加 | 形式 | 系统/链接 | 备注 |
|---|---|---|---|---|---|---|---|
| 某校某学院 | 7-12 12:00 | 是 | 是 | 是 | 线下 | 链接 | 需推荐书 ×2 |

用法的三条纪律：

- **截止时间精确到时分**，只写日期等于没写；
- **是否报名在你点下提交键的当天更新**，凭印象填表是 501 那次「时间冲突忘了」翻车的根源；
- **备注列存差异项**：这所学校独有的材料（政审表、承诺书）、特殊的命名要求、开放日需要提前预约之类的信息，全塞备注。

## 模板二：营期现场记录卡

每参加一场营或一次面试，当天写一张卡。字段如下：

- **基本信息**：日期、学校/学院、考核形式（单面/群面/笔试）、时长、我的优先级（A/B/C，见 506）；
- **材料版本**：这次投的是哪个版本的个人陈述/简历（记文件名或版本号）——复盘「哪版材料通过率更高」全靠这列；
- **流程实录**：环节顺序，各环节几分钟，有没有抽题、英文环节、PPT；
- **被问到的问题**：尽量原话记，按顺序列。这是你的私人真题库，比任何网上流传的题都准；
- **卡壳的地方**：哪题卡了、当时怎么答的、正确思路是什么（参考 502 的复盘法）；
- **接触到的老师与博士生**：方向关键词、说话时透露的招生信息、组会频率之类的一手情报；
- **自我评价与结果**：当天表现打几分、结果（优营/候补/无）、下一步动作（跟进邮件/等候补/放弃）。

当时我一天的真实记录长这样：

> - [x] 某校学术开放日 ✅ 用时 22min
> - [x] 面试准备：ppt ✅ ／ 阅读老师研究方向 ✅
> - [x] 判断合不合算 ✅ 17min
> - [x] 套磁邮件 10 封 ✅（1–10 逐条打勾）
> - [ ] 玩游戏 1h（15min）

看起来琐碎，但每一条都有用：22 分钟的开放日让我知道这类活动值不值得去；「先判断合不合算」那一项让我在动手前先做了取舍，省掉了两场没必要去的营。

## 复盘：营季结束前做一次汇总

所有单场卡写完，9 月预推免报名前做一次横向复盘，回答四个问题：

1. **哪类考核形式我表现最好？**（单面 PPT 型还是追问型——预推免选项目时参考）
2. **哪类问题反复出现？**——高频题直接进入面试题库重点准备（配合第六章）；
3. **哪版材料带来的面试最多？**——预推免统一用这版；
4. **我的 A 类名单更新了吗？**——根据营期实际观察（导师、氛围、去向）调整预推免志愿优先级。

记录的全部价值在于：**让你用一个暑假的真实数据做 9 月的决策，而不是凭感觉。** 模板就这两张，坚持记，营季结束时你会比 90% 的人清楚自己该去哪。
