# 多场面试的时间与精力分配

7 月我的清单上同时挂着七八场考核：某市同城两三场连着排，外地的线上线上混着来。最密的一天上午一场下午准备一场。这段日子教会我的不是「怎么把每场都考好」，而是「怎么承认考不好所有场，然后分配」。

## 先把牌摊在桌上

精力分配的前提是看见全部场次。把所有面试按地区和时间排进一张清单，我当时的版本长这样（按片区分组）：

| 片区 | 学校/学院 | 日期 | 形式 | 我的优先级 |
|---|---|---|---|---|
| 某东部片区 | 某校某学院 | 7-9 | 线上 | A |
| 某东部片区 | 某校某学院 | 7-11 | 线下 | A |
| 某中部片区 | 某校某学院 | 7-13 | 线下 | B |
| 西南片区 | 某校某学院 | 7-17 | 线下 | C |
| …… | | | | |

优先级不是按学校名气排的，按三个变量：**方向匹配度、拿到 offer 的概率、这个 offer 对你的实际价值**。三者乘起来高的是 A，只能占一个的是 B，陪跑的诚实标 C。标 C 不丢人，丢人的是 C 场面试前一晚还在熬夜准备，第二天 A 场面试睡着。

## 分配法则：A 场吃肉，C 场保底

- **A 场：满配。** 读齐目标导师的方向（套磁档案现成的）、过一遍 PPT、预演高频问题。一场 A 类的准备时间给到其他场次的 3–5 倍，毫不可惜。
- **B 场：通用配置。** 只做三件事：确认材料带齐、路线/设备测好、把自我介绍和项目讲一遍。B 场的目标不是优秀，是不失误。
- **C 场：保底配置。** 确认报名有效、知道时间和形式、到场/上线。心态是白捡的，考好是惊喜。**C 场冲突时直接放弃，别犹豫超过五分钟**——犹豫的时间本来够你准备半场 A。

排队候补同理：把「必保的场」空出来，候补能插就插，插不上拉倒。507 讲的捡漏机会，往往就诞生在别人 A 场撞车而你 C 场保底的错位里。

## 恢复：场与场之间做什么

面试是重体力活动。一场 30 分钟高强度对话下来，脑子是糊的，直接压下一场只会两场都砸。我的恢复流程后来固定成三步：

1. **当场收尾 10 分钟。** 走出面试间，先在纸上记三行：被问了什么、哪题卡了、下一位面试官可能追问什么（同一学院面试官间经常共用题面）。这一步复用价值最高，别拖到晚上。
2. **物理切换。** 吃顿正经饭、走一段路、睡 20 分钟。不要立刻复盘到深夜——上一场的情绪会污染下一场的状态，502 那次翻车我第一晚就是这样把第二场也搭进去的。
3. **只做下一场的最小准备。** 恢复完看下一场的准备卡：对方学院的形式、老师方向关键词、我的两个钩子。到此为止，不多准备。

## 日常作息：把状态当资源管

扎堆期别再谈「每天学到几点」，改成管三块时间：

- **上午给最难的事**：读老师论文、预演问答，脑子最清楚的时候干认知最重的活。
- **下午给流程性的事**：改材料、填系统、订行程，这类事错峰做。
- **面试日前夜只做收尾**：材料装袋、路线确认、PPT 过一遍，11 点前睡。面试状态的一半是睡出来的。

多场面试季本质上是一道资源题：时间是预算，状态是现金流，优先级就是投资决策。把 C 场果断砍掉的人，A 场才有余粮。
